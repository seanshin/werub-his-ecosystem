# 임상 경로 — 건너뛴 단계를 완료로 세지 않고, 이탈은 숨기지 않는다

**Clinical pathways — skipped steps are not counted as done, and deviations are not hidden**

> **EN** — A clinical pathway is a standard day-by-day plan (milestones by day, a target length of stay, an optional DRG code) that is drafted, published, assigned to a patient's encounter and then followed step by step. Only milestones recorded as **done** count as done: skipped, delayed and deviated steps never raise the progress bar, and progress and automatic completion come from **one formula**, so "100%" and "completed" always mean the same moment. Deviation is kept as a **count, not a status**, so a pathway with deviations is still visibly in progress and can still be recorded against. Completion and deviation rates are returned **with their numerators and different denominators**, and with no sample they are "not computable", not 0%. Publishing asks the committee-governance check for a resolution number; by default it **warns rather than blocks** (stopping a standard already applied to patients would halt care) and records who published — the base-commit screen does not send a resolution number, so publishing from it is recorded as "no resolution on record". Sits on judgment rules ① honesty, ② single source of truth, ④ gates, ⑥ human decisions and ⑦ numbers.

## 1. 무엇을 하나

진단이나 수술별로 **입원 며칠째에 무엇을 하는지**를 표준으로 정해 두고, 환자에게 적용해 **따라갔는지**를 기록합니다.

| 무엇 | 내용 |
|---|---|
| 경로 | 코드 · 이름 · 진료과 · 표준 재원일 · (선택) DRG 코드 · 설명 |
| 마일스톤 | **며칠째** · 분류(평가 · 오더 · 투약 · 교육 · 퇴원 등) · 제목 · **필수 여부** |
| 배정 | 경로를 **환자의 진료(입원)** 에 붙입니다 — 시작일이 기준입니다 |
| 결과 | 마일스톤마다 **완료 · 건너뜀 · 지연 · 이탈** 넷 중 하나와 사유 |
| 분석 | 경로별 **완료율 · 이탈률 · 평균 실제 재원일** |

🔴 **「경로」라는 이름의 기능이 하나 더 있습니다.** 응급실의 [골든타임 프로토콜](emergency-pathway.md)은 **분 단위**로 한 환자의 시간 민감 단계를 찍는 **추적기**이고 템플릿이 코드에 고정된 세 가지뿐입니다. 이 글의 임상 경로는 **일 단위** 입원 표준이고, **기관이 만들고 발행하는 문서**입니다. 둘은 데이터도 화면도 다르고 서로 이어져 있지 않습니다.

## 2. 어떻게 도나

### ① 만들기 · 발행 — 🔴 **막지 않되, 근거 없이 눌렀다는 사실이 남는다**

| 상태 | 뜻 |
|---|---|
| 초안 | 만들고 고치는 중 — **배정할 수 없습니다** |
| 활성 | 발행됨 — 환자에게 배정할 수 있습니다 |
| 폐기 | 더는 쓰지 않음 |

- 경로와 마일스톤을 만들고 고치고 발행 · 폐기 · 복제하는 것은 **관리자**입니다. 의사(와 관리자)가 **배정**하고, 의사 · 간호사가 **결과를 기록**합니다.
- 🔴 **발행하면 위원회 요건을 평가합니다**([위원회 의결](governance-enactment.md)). 기준 커밋의 유형 기본값은 「발효에는 의결이 필요하다 · 모드는 **경고**」입니다 — 의결번호가 없어도 **발행은 되고**, 판정 결과가 **응답에 함께** 담깁니다.
- 발행한 사람 · 시각 · 제시된 의결번호를 경로에 남깁니다. 의결번호가 비어 있으면 그 표준은 **「의결 근거 없음」**으로 남습니다.
- 🔴 **기준 커밋 화면의 발행 단추는 의결번호를 보내지 않습니다.** 그래서 화면에서 발행하면 **언제나 「의결 근거 없음」**으로 기록되고, 화면은 판정을 보여 주지 않고 「발행되었습니다」만 띄웁니다.
- **복제**는 새 버전을 초안으로 만들고 마일스톤을 그대로 복사합니다.

### ② 배정 — 🔴 **시작일은 추정하지 않는다**

| 규칙 | 내용 |
|---|---|
| 활성 경로만 | 초안 · 폐기 경로는 배정을 거절합니다 |
| 중복 거부 | 같은 환자 · 같은 경로에 **진행 중인 배정이 이미 있으면** 거절합니다 |
| 🔴 시작일 필수 | 없거나 날짜가 아니면 **이유를 말하고 거절**합니다 |

시작일은 경과일 · 진행률 · 실제 재원일 계산의 기준이라 **없으면 지어내지 않습니다.**

### ③ 결과 기록 — 🔴 **완료만 완료다**

| 규칙 | 내용 |
|---|---|
| 네 상태 | 완료 · 건너뜀 · 지연 · 이탈 — 그 밖의 값은 거절 |
| 소속 확인 | 🔴 **이 배정의 경로에 속하지 않는 마일스톤**이면 거절합니다 |
| 재기록 | 같은 마일스톤을 다시 기록하면 **새 행을 만들지 않고 갱신**합니다 |
| 이탈 수 | 🔴 **상태가 바뀔 때만** 늘고 줍니다 — 같은 이탈을 두 번 기록해도 한 번입니다 |
| 실제 일차 | 보내지 않으면 **시작일로부터 계산**합니다 |
| 진행 중만 | 완료 · 취소된 배정에는 기록하지 않습니다 |

🔴 **자동 완료** — **필수 마일스톤이 모두 「완료」로 기록된 순간** 배정이 완료되고 실제 재원일이 찍힙니다(필수가 하나도 없으면 전체 마일스톤이 기준). 필수 마일스톤을 **건너뛰거나 이탈로 기록하면 자동 완료되지 않습니다** — 그 배정은 사람이 정리합니다(취소).

- 결과 기록의 **수행자 칸**은 요청이 보낼 때만 채워지고, 기준 커밋 화면은 보내지 않습니다. 누가 기록했는지는 **공통 감사 기록**에 남습니다.
- 사유(이탈 사유) 칸은 **자유 기재**이고 필수가 아닙니다.

### ④ 진행률 — 🔴 **한 산식**

목록 · 상세 · 자동 완료 판정이 **같은 함수**를 씁니다.

| 값 | 뜻 |
|---|---|
| 분모 | **필수 마일스톤 수**(없으면 전체) = 자동 완료 판정과 같은 집합 |
| 분자 | 그중 **「완료」로 기록된 수** — 건너뜀 · 지연 · 이탈은 세지 않습니다 |
| 🔴 마일스톤 0개 | 0% 가 아니라 **산출 불가** |

그래서 **「진행률 100%」와 「자동 완료」가 언제나 같은 순간**을 가리킵니다.

### ⑤ 🔴 이탈은 상태가 아니라 수다

배정 상태는 진행 중 · 완료 · 취소 셋뿐이고, 이탈은 **배정마다 센 수**로 남습니다. 목록은 **「이탈 발생분만」**(이탈 1건 이상)으로 거르고, 배정 카드에 **「이탈 N건」**을 따로 붙입니다. 이탈이 있어도 배정은 계속 진행 중이고 **이후 결과를 계속 기록할 수 있습니다.**

### ⑥ 🔴 분석 — 두 비율의 분모가 다르다는 것을 응답이 말한다

| 지표 | 분자 / 분모 | 표본이 없으면 |
|---|---|---|
| 완료율 | 완료된 배정 / **전체 배정** | 산출 불가 |
| 이탈률 | 이탈이 있는 완료 배정 / **완료된 배정** | 산출 불가 |
| 평균 실제 재원일 | 완료된 배정만 | 산출 불가 |

비율만이 아니라 **분자와 분모를 함께** 돌려줍니다. 진행 중 · 취소 건수도 따로 냅니다. 화면은 「적용 0건은 ‘이탈 없음’이 아니라 **알 수 없음**」이라고 적습니다.

### ⑦ 다른 기능이 이 기록을 읽는 자리

| 누가 | 무엇을 |
|---|---|
| 원무 — 입원 미청구 현황 | 입원 진료에 **진행 중인 배정**이 있으면 그 경로의 **표준 재원일**을 함께 냅니다(포괄수가 환산용) |
| 환자 일정표 | 진행 중 배정의 마일스톤을 **며칠째 날짜**에 그립니다 — 🔴 여기서는 결과가 **기록되기만 하면 상태와 무관하게 「완료」**로 그립니다. 경로 화면의 진행률(「완료」만 셈)과 **기준이 다릅니다** |

### ⑧ 설치 직후 — 예시 경로 다섯

시드가 **예시 경로 5개**(각 6개 마일스톤)를 **곧바로 활성**으로 넣습니다. 🔴 **설치 확인용 예시이지 임상 내용이 아닙니다** — 발행 기록이 없으므로 「의결 근거 없음」으로 보입니다. 기관의 경로는 기관이 만들고 위원회가 정합니다.

## 3. 🔴 왜 그렇게 만들었나

- 🔴 **완료만 완료로 세는 이유.** 한때 목록 진행률은 **상태와 무관하게 기록 수**를 셌고, 자동 완료는 필수가 전부 완료일 때만 일어났습니다. 여섯 단계를 **전부 「건너뜀」으로 기록해도 목록은 100% 초록 막대**였습니다. 건너뜀 · 지연 · 이탈은 **완료가 아닙니다**(판정 규칙 ①).
- **산식을 하나로 모은 이유.** 두 벌이면 **「100%인데 완료가 아니다」**가 생깁니다. 진행률의 분모를 자동 완료 판정의 대상과 **같게** 둔 것도 그래서입니다. 상세 화면은 한동안 진행률 필드를 받지 못해 **언제나 0%** 였습니다(판정 규칙 ②).
- **이탈을 상태로 만들지 않은 이유.** 배정 상태에 「이탈」을 쓰는 코드는 없었고, 화면의 「이탈」 필터는 **영구 0건**, 이탈 5건인 배정도 배지는 「진행 중」이었습니다. 상태를 바꾸면 이후 기록이 거절되므로, **사실 그대로 「이탈 발생」 조건으로 거릅니다**(판정 규칙 ①).
- 🔴 **표본 0을 산출 불가로 두는 이유.** 적용된 배정이 없는데 완료율 0% · 이탈률 0% 를 돌려주면 화면은 **「이탈 없음 · 양호」**로 읽습니다. 분모가 없으면 비율이 아닙니다([분모 없는 비율을 내지 않는다](no-ratio-without-denominator.md) · 판정 규칙 ⑦).
- **두 분모를 응답에 함께 싣는 이유.** 비율만 보내면 화면은 이탈률을 **완료율의 분모(전체 배정)** 로 읽습니다.
- **시작일을 추정하지 않는 이유.** 시작일 없이 오면 날짜가 깨져 저장 단계에서 실패했고, 화면은 **「경로 적용에 실패했습니다」만** 띄웠습니다. 배정이 0건이던 한 원인이었습니다. 기준값은 **지어내지 않고 요구합니다**(판정 규칙 ⑦).
- **중복 배정 · 소속 확인 · 재기록 갱신을 둔 이유.** 같은 환자에게 같은 경로가 둘이면 진행률과 이탈이 **두 갈래로 갈라지고**, 다른 경로의 마일스톤으로 기록하면 완료 판정이 오염되고, 중복 행은 **조기 완료**를 만들었습니다(판정 규칙 ②).
- 🔴 **발행을 막지 않는 이유.** 코드가 이렇게 적습니다 — 적용 중인 표준을 근거가 없다는 이유로 멈추면 **안전측이 아니라 진료 중단**입니다. 대신 **발행자와 의결 근거를 남겨** 「근거 없이 발효된 표준」 목록이 줄어드는 것을 볼 수 있게 합니다. 막을지(차단 승격)는 **위원회가 정합니다**(판정 규칙 ④ · ⑥).
- **근거(문헌 등)를 기본으로 요구하지 않는 이유.** 강제하면 **아무 문장이나 채워집니다** — 기본 규칙이 그렇게 적습니다.
- 🔴 **찾지 못한 것**
  - **이탈률의 분모를 「완료된 배정」으로 둔 이유** — 주석은 두 분모가 다르다는 사실만 적고, 왜 진행 중 · 취소 배정의 이탈을 빼는지는 적지 않습니다.
  - **필수 마일스톤을 건너뛴 배정을 어떻게 닫을지**의 방침 — 자동 완료되지 않는다는 것까지만 코드에 있습니다.
  - **환자 일정표가 상태와 무관하게 「완료」로 그리는 이유**를 찾지 못했습니다.

## 4. 🔴 무엇을 막나

- **초안 · 폐기 경로를 환자에게 배정하는 것**
- **같은 환자 · 같은 경로의 이중 배정**
- **시작일 없는 배정** — 이유를 말하고 거절합니다
- **건너뛴 단계를 완료로 세는 것** — 진행률과 자동 완료가 「완료」만 셉니다
- **다른 경로의 마일스톤으로 기록하는 것**
- **같은 기록이 두 번 세어지는 것** — 재기록은 갱신이고, 이탈 수는 상태 전이로만 움직입니다
- **이탈이 배지 뒤로 숨는 것** — 이탈은 수로 따로 붙습니다
- **표본 없는 비율** — 산출 불가로 냅니다
- **누가 발행했는지 모르는 표준** — 발행자 · 시각 · 의결번호 칸이 남습니다
- **막지 못하는 것**
  - 🔴 **경로 내용의 임상 타당성은 판정하지 않습니다** — 어떤 단계를 며칠째에 둘지는 **기관과 전문가가 정하고 위원회가 정하는 일**입니다
  - 🔴 **의결 없는 발행** — 기준 커밋 기본은 **경고**이고, **화면 발행은 의결번호를 보내지 않아** 늘 「의결 근거 없음」으로 남습니다
  - **필수 마일스톤을 건너뛴 배정은 스스로 닫히지 않습니다** — 사람이 취소해야 목록에서 빠집니다
  - **이탈 사유는 필수가 아닙니다**
  - **환자 일정표와 경로 화면의 「완료」 기준이 다릅니다**(§2 ⑦)
  - **결과가 기록된 마일스톤은 지울 수 없습니다** — 데이터베이스가 거부하고, 화면은 「삭제에 실패했습니다」만 띄웁니다

- 🔴 **실제 호출로 확인하지 않았습니다.** 새 설치본 따라가기에서 경로 발행 · 배정 · 결과 기록 · 분석을 **부르지 않았습니다** — 임상 경로 화면은 캡처돼 있으나(가상 병원 데이터), 이 글은 기준 커밋 코드를 읽은 것입니다([따라가 본 결과](../../build-guide/follow-along-2026-09.md)).

- 🔴 **이 글은 진료 지침이 아닙니다.** 예시 경로의 단계와 일수는 설치 확인용이고, 표준 재원일 · 마일스톤 구성은 **기관이 관할 규정과 자기 근거로 정할 값**입니다.
- 이 기능은 **한 시스템 안**에서 끝나므로 [연결 상태 표](../../RELEASES/2026.09/compatibility.md)에는 나오지 않습니다.
