# 유전체 이차 소견 — 동의가 없으면 건수조차 보여 주지 않는다

**Secondary findings — without consent, not even the count is shown**

> **EN** — For genomic secondary findings the system does not merely hide the detail when consent is absent: it does not show the **count** either. Showing "3 findings, consent required" would already disclose that something was found, which is itself the information the patient chose not to receive. Sits on judgment rule ① — a number shown without its precondition is not neutral.

## 1. 무엇을 하나

유전체 · NGS 에서 **이차 소견**(원래 목적 외에 발견된 것)은 환자의 동의가 있어야 다룹니다.

## 2. 어떻게 도나

| 단계 | 무엇이 일어나나 |
|---|---|
| 동의 | 검사 전 동의에 이차 소견 항목이 포함됩니다 |
| 판정 | 큐레이션에서 이차 소견이 분류됩니다 |
| 게이트 | 🔴 **동의가 없으면 건수조차 보여 주지 않습니다** |
| 보고 | 동의가 있으면 해석을 확정하고 보고서를 서명·배포합니다 |
| 재분류 | 나중에 근거가 바뀌면 재분류합니다 |

## 3. 🔴 왜 그렇게 만들었나

- **「3건 있음 · 동의 필요」라고 적는 순간 이미 알려 준 것입니다.** 무언가 발견됐다는 사실 자체가 환자가 받지 않기로 한 정보입니다.
- 그래서 **가리는 것이 아니라 세지 않은 것처럼** 보여야 합니다. 숫자를 보여 주고 내용을 가리는 흔한 방식으로는 이 약속을 지킬 수 없습니다.
- 🔵 근거: LIS 구성서 §4 「이차 소견 동의 게이트(동의가 없으면 건수조차 보여 주지 않음)」 · 판정 규칙 ①.

## 4. 🔴 무엇을 막나

- 동의 없이 **존재 사실이 새는 것**
- 「건수만 보여 주는」 절충
