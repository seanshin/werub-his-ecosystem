# 보유·파기 — 세기는 하고, 지우지는 않는다

**Retention — it counts what is due, and deletes almost nothing**

> **EN** — Retention policies per record type exist, a nightly job counts what has passed its period, and the screen shows the result. What it does **not** do is delete: of five seeded policies, only one — inactive pre-boarding accounts — has a purge handler, and that one only flips a flag. Medical records, prescriptions, consent forms and access logs are counted and never purged; the anonymize action exists as a label with no implementation. Four gates guard the purge endpoint anyway (a global switch off by default, a legal-confirmation flag, a statutory-minimum clamp and a two-person approval), and no screen or scheduler calls it. The screen says so in plain words. Wired in code but **not verified by real calls**.

## 1. 무엇을 하나

의무기록은 **정해진 기간 동안 반드시 보관해야 하고**, 그 기간이 지나면 **지워도 되거나 지워야** 합니다. 이 기능은 기록 종류별로 그 기간을 등록하고, **기간이 지난 건이 몇 건인지 세어** 보여 줍니다.

🔴 **그리고 거기까지입니다.** 이 자료가 이 편을 쓰는 이유가 그것입니다 — **화면 이름은 「보유·파기」인데, 실제로 파기가 도는 경로는 없습니다.** 그 사실을 그쪽 화면이 직접 적고 있습니다.

## 2. 어떻게 도나

### 등록된 정책과 실제로 지울 수 있는 것

설치 직후 들어오는 정책은 다섯이고, **그중 실제로 파기 처리가 붙어 있는 것은 하나**입니다.

| 기록 종류 | 정책 | 파기 처리 |
|---|---|---|
| 진료기록부 | 10년 · 「익명화」 | 🔴 **없음** — 세기만 합니다 |
| 처방전 | 2년 · 「보고만」 | 🔴 없음 |
| 동의서 | 5년 · 「보고만」 | 🔴 없음 |
| 접속기록(감사 로그) | 3년(법정 하한 1년) · 「보고만」 | 🔴 **일부러 없음** — 법정 보존이라 파기가 아니라 보관 이관의 대상입니다 |
| 미활성 임시 계정 | 30일 · 「비활성화」 | 🟢 있음 — **행을 지우는 것이 아니라 비활성으로 바꿉니다** |

🔴 **「익명화」는 고를 수 있는 값으로만 있고, 익명화를 수행하는 코드는 없습니다.**
🔴 **되돌릴 수 없는 삭제(hard delete)는 구현돼 있지 않습니다** — 관계가 얽힌 데이터를 지우는 위험 때문이라고 코드가 적고 있습니다.

### 매일 도는 것 — 세기만 한다

밤마다 한 번, **기간이 지난 건이 몇 건인지 세어** 정책 행에 적습니다. 🔴 **아무것도 지우지 않습니다.**
🔵 다만 **읽기 전용은 아닙니다** — 마지막 실행 시각과 후보 수를 갱신하므로, 화면이 열릴 때 자동으로 돌리지 않습니다.

🔴 **핸들러가 없는 종류의 「0 건」은 「0 건」이 아니라 「세지 않음」입니다.** 화면이 그것을 0 으로 그리지 않습니다 — [취지 1](../../overview/02-principles.md).

### 실제로 지우려면 — 네 겹을 다 통과해야 한다

| 겹 | 무엇 |
|---|---|
| ① 전역 스위치 | 기본 **꺼짐**. 꺼져 있으면 「후보 세기만 가능」 |
| ② 법무 확정 | 정책마다 **법무가 기간을 확정했다는 표시**가 있어야 합니다(설치 직후 다섯 모두 **미확정**) |
| ③ 법정 하한 클램프 | 등록 기간과 법정 하한 중 **더 긴 쪽**을 씁니다 — 하한 안쪽은 지우지 않습니다 |
| ④ 2인 승인 | 요청과 승인이 **다른 사람**이어야 하고, 승인은 24시간 안에 한 번만 쓰입니다 |

그리고 실행하면 **누가 무엇을 몇 건 지웠는지 감사 기록에 남습니다.**

🔴 **그 경로를 부르는 화면도, 스케줄러도 없습니다.** 사람이 API 를 직접 불러야만 도는 자리이고, 화면에는 실행 단추를 **일부러 그리지 않았습니다.**

### 🔴 그런데 실제로 행을 지우는 곳은 따로 있다

**알림**은 이 정책과 **연결되지 않은 자기 크론**을 가지고 있고, 매일 **읽은 알림 90일 · 안 읽은 알림 180일**이 지나면 **행을 정말로 지웁니다.** 코드가 그 옆에 이렇게 적어 두었습니다 — **「미읽음은 이 일수 뒤 삭제된다(원장이 사라진다)」**.
→ 기관이 알아야 할 것: **「보유·파기」 화면이 이 삭제를 관장하지 않습니다.**

## 3. 🔴 왜 그렇게 만들었나

- **지우는 것보다 못 지우는 것이 낫다.** 법정 보존기간 안쪽의 기록을 조기에 파기하는 것은 되돌릴 수 없습니다. 그래서 기본을 **세기만 하는 것**으로 두고, 지우려면 네 겹을 통과하게 했습니다(판정 규칙 ④·⑥).
- **고위험 기록의 파기는 「아직 설계하지 않았다」고 적는다.** 진료기록·처방전·동의서에 파기 처리를 붙이지 않은 것은 빠뜨린 것이 아니라 **법무와 설계가 끝나지 않아 붙이지 않은 것**이고, 코드가 그렇게 적고 있습니다. 목록에서 빼지 않고 **「세기만 함」으로 남겨 둔 것**이 이 생태계의 방식입니다(판정 규칙 ①).
- **접속기록은 파기 대상이 아니라 보관 이관 대상이다.** 그래서 파기 처리를 **일부러 두지 않았습니다.**
- **화면이 없는 능력을 약속하지 않는다.** 실행 단추를 그리지 않고, 화면 위에 **「현재 실제 파기가 도는 경로는 없습니다」**라고 적습니다. 그쪽 화면 검사도 **「파기 실행을 부르지 않는다」는 것을 시험으로 못 박고** 있습니다 — 「가짜 게이트 금지」의 반대쪽입니다(판정 규칙 ①·③).
- **보존기간의 정본을 하나로 모았다.** 감사 로그 보존일을 설정 값과 정책 행 **두 곳에서 정하던 것**을 정리해, 설정 쪽을 없앴습니다. 같은 것을 두 곳에서 정하면 어느 쪽이 사실인지 아무도 모르게 됩니다(판정 규칙 ②).
- **규정을 자동 집행하는 경로에서 파기만 뺐다.** 원내 규정을 시스템 설정에 자동으로 반영하는 장치가 있는데, **파기 실행만은 거기에 묶지 못하게** 막아 두었습니다 — 2인 승인 경로만 유효하다는 뜻입니다.

## 4. 🔴 무엇을 막나

- **법정 하한 안쪽의 조기 파기** — 등록 기간이 하한보다 짧아도 **실행 시점에 더 긴 쪽**이 적용됩니다
- **법무 확정 없는 파기** — 정책마다 확정 표시가 없으면 거부합니다
- **혼자 하는 대량 파기** — 요청자와 승인자가 달라야 하고, 승인은 한 번만 쓰입니다
- **규정 자동화를 통한 우회** — 파기 실행은 자동 집행 대상에서 제외돼 있습니다
- **실수로 누르는 것** — 화면에 실행 단추가 없고, 확인 값 없이는 호출이 거부됩니다
- **「세지 않음」을 「0 건」으로 보이게 하는 것** — 화면이 둘을 갈라 말합니다

## 5. 🔴 기관이 알아야 할 것

| 무엇 | 지금 상태 | 기관이 할 일 |
|---|---|---|
| **나라별 보존기간** | 🔴 **축이 없습니다.** 기본값은 한국 기준으로 들어오고, 기록 종류마다 **행이 하나뿐**이라 나라별로 다른 기간을 나란히 둘 수 없습니다 | 다른 나라에 세우면 각 행의 값을 직접 고칩니다 |
| **실제 파기** | 🔴 **도는 경로가 없습니다.** 진료기록·처방전·동의서는 기간이 지나도 그대로 남습니다 | 파기가 필요하면 **기관이 별도로 설계**해야 합니다. 개시 준비의 「법무 승인」 항목이 이것입니다 |
| **보존명령(소송·조사 중 보존)** | 🔴 이 기능에는 **없습니다**(진료 녹음 쪽에만 따로 있습니다) | 운영 규정으로 다룹니다 |
| **알림의 자동 삭제** | 🔴 이 화면과 **무관하게** 돌고, 행을 정말로 지웁니다 | 보관이 필요하면 설정 값을 올립니다 |
