# 마약류 수불 원장 — 나가지 않은 보고를 「제출 완료」로 적지 않는다

**Controlled-substance ledger — an unsent report is never recorded as filed**

> **EN** — Two ledgers run side by side: a per-patient chain (prescribe → second check → dispense → administer → waste/return) and a perpetual stock book for the narcotics safe, with every movement row-locked and written as an append-only transaction. Disposal, adjustment and any counted discrepancy require an **independent witness who must be a real active user, not a typed name**. The statutory report channel to the national controlled-substance system is **not implemented**: the software builds the batch file and says so in the response, and the only thing that marks a report as received is a receipt number a person types back in. Wired in code but **not verified by real calls** — the follow-along never exercised this area.

## 1. 무엇을 하나

마약·향정신성의약품은 「썼다」가 아니라 **「한 톨까지 어디로 갔는지 대조된다」**가 요구되는 약입니다. 이 기능은 두 개의 장부를 나란히 돌립니다.

| 장부 | 무엇을 센다 | 왜 둘인가 |
|---|---|---|
| **환자별 취급 원장** | 처방 → 2차 확인 → 불출 → 투여 → 폐기 · 반납 | 「이 환자에게 얼마가 갔나」 |
| **영속 재고 수불부** | 금고의 장부 잔량 + 입고 · 불출 · 반납 · 폐기 · 조정 · 실사 | 「금고에 얼마가 남아야 하나」 |

그 위에 **사고(도난 · 분실 · 파손 · 재해) 기록**과 **법정 취급보고 대기열**이 붙습니다. 두 장부가 어긋나는 순간이 곧 **유용(diversion) 을 의심할 자리**입니다.

## 2. 어떻게 도나

### 환자별 원장 — 한 방향으로만 간다

| 단계 | 무엇이 일어나나 |
|---|---|
| 처방 | 오더에 마약류 약품이 들어오면 원장이 **자동으로 열립니다** |
| 2차 확인 | 🔴 **처방한 사람은 확인할 수 없습니다** |
| 불출 | 확인된 건만 불출되고, 같은 순간 **금고 수불부에서 차감**됩니다 |
| 투여 | 불출된 건만 투여할 수 있고, **투여량이 불출량을 넘을 수 없습니다** |
| 폐기 | 🔴 **사유 + 독립 증인 필수**. 그리고 **투여량 + 폐기량 ≤ 불출량**을 넘으면 거부합니다 |
| 예외 | 같은 건에 두 요청이 동시에 오면 **뒤엣것이 충돌로 거부**됩니다(이중 불출 · 이중 투여 방지) |

한국 분류(마약 / 향정 / 대마, 향정 가·나·다·라)를 **따로 들고** 있습니다 — 법정 보고의 키이기 때문입니다.

### 금고 수불부 — 모든 이동이 잔량 앞뒤와 함께 남는다

- 이동마다 **직전 잔량 · 직후 잔량 · 수행자 · (있으면) 증인 · 차이**가 한 줄로 쌓입니다. **이 줄은 고치거나 지우는 경로가 없습니다.**
- 동시 이동은 **줄을 잠가 한 줄씩** 처리합니다 — 겹쳐 쓰면 잔량이 어긋나고, 어긋난 잔량은 초과 불출을 덮어 줍니다.
- 장부보다 많이 불출하려 하면 **기본값은 거부**입니다(기관이 `경고`나 `끔`으로 낮출 수 있습니다).
- 🔴 **단 한 곳만 예외** — 약국 조제로 이미 물리적으로 나간 건은 **장부가 반드시 따라갑니다.** 잔량이 모자라면 **음수로 적고 경보**를 냅니다. 「거부」로 삼키면 **장부가 물리보다 많아져 유용이 감춰지기** 때문입니다.

### 실사(재고 조사) — 차이를 덮지 않는다

| | |
|---|---|
| 차이가 없으면 | 조용히 끝납니다 |
| 차이가 있는데 증인이 없으면 | 🔴 **기록조차 남기지 않고 거부**합니다 |
| 차이 + 증인이 있으면 | 장부를 **실사값으로 확정**하고, 직전 · 직후 · 차이를 남긴 뒤 **「유용 의심」 경보**를 올립니다 |

### 법정 취급보고 — 🔴 이 생태계가 **하지 않는** 것

**국가 마약류 통합관리 시스템으로 나가는 전송은 구현돼 있지 않습니다.** 소프트웨어가 하는 일은 여기까지입니다.

1. 보고할 사건을 대기열에 쌓습니다
2. 제출용 배치 파일(CSV · XML)을 만들어 줍니다
3. 🔴 내려받는 응답에 **「전송되지 않았음」을 표시**로 붙입니다
4. 사람이 그 파일을 올리고 **받은 접수번호를 입력**해야 비로소 `접수됨`이 됩니다

→ 대기열에 남은 건은 **다음 배치에 다시 담깁니다.** 통계도 연동이 붙기 전에는 그 건들을 **미전송으로 셉니다.**
→ 사고 기록도 「신고한 사실의 기록」이지 **전송이 아닙니다.**

## 3. 🔴 왜 그렇게 만들었나

**이 기능의 「왜」는 대부분 한 번 틀렸다가 고친 자리에서 나왔습니다.** 코드 주석과 릴리즈 기록이 그것을 지우지 않고 적어 두었습니다.

- **없는 연동을 흉내내지 않는다.** 종전에는 **배치 파일을 만들기만 하면 그 보고들이 「제출 완료」로 확정**됐습니다. 전송 코드는 어디에도 없었는데 말입니다. 그래서 내려받기만 하고 올리지 않아도 원장은 제출됐다고 말했고, **그 보고는 다음 배치에서 영구히 빠졌습니다.** 지금은 나가지 않았으면 「원내 기록」이고, **전송 시각을 모르면 추정하지 않으며**, 미전송은 항상 다시 담깁니다. 판정 규칙 ①(모르는 것을 아는 척하지 않는다)·⑥(발신은 구현 + 설정 + 승인).
- **이미 저장된 값은 바꾸지 않는다.** 과거에 「제출 완료」로 적힌 줄은 지우지 않고, **읽는 쪽에서 「전송 근거 없음」으로 분류**합니다. 일어난 사실을 소급해 고치지 않습니다(판정 규칙 ⑦).
- **증인은 이름이 아니라 사람이어야 한다.** 화면은 입회자를 **성명 문자열**로 보내고 서버는 그것을 사람 식별자로 받도록 돼 있어, **개통 이래 폐기 기록이 100% 실패**하고 있었습니다. 동시에 「증인 ≠ 수행자」 비교도 무력해져 **혼자 폐기**가 통과할 수 있는 모양이었습니다. 지금은 증인이 **실재하고 활동 중인 직원**인지 확인하고, 본인을 뺀 후보 목록을 따로 내려 줍니다(판정 규칙 ②·③).
- **검증을 건너뛰는 입력 자리가 있었다.** 투여량이 검증을 타지 않아 **음수 투여량**이 원장에 들어가고 법정 보고에 음수로 나갈 수 있었습니다. 지금은 입력 단계와 서비스 단계 **양쪽에서** 막습니다.
- **모르는 값을 0 으로 채우지 않는다.** 폐기량이 적히지 않은 건이 섞이면 그날 잔량은 **0 이 아니라 「산출 불가」**이고, 왜 그런지를 함께 적습니다. 폐기 시각 칸이 스키마에 아예 없어서, 날짜별 집계는 **추정하지 않고** 무엇을 기준으로 삼았는지 밝힙니다(판정 규칙 ①).
- **소수 잔차가 잔량에 섞이면 안 된다.** 합계를 십진 수로 누적합니다 — 부동소수점으로 더하면 마약류 잔량에 잔차가 남습니다.
- **날짜를 조용히 고쳐 읽지 않는다.** 잘못된 날짜가 다음 해로 굴러가면 **원장과 사고 발생일이 다른 날**이 됩니다. 그래서 형식이 틀리면 거부합니다.
- **열람까지 법정 기록이다.** 이 영역은 **목록을 보는 것만으로도** 감사 기록에 남습니다.
- 🔴 **왜 그 화면들이 오래 조용했나** — 목록 응답을 화면이 잘못 읽어 **늘 비어 있었고, 그 빈 값으로 「미확인 0 · 오늘 처방 0 · 폐기 0」이라고 단정**했습니다. 수불부 · 실사 불일치 · 사고 기록은 **부르는 화면이 아예 없었습니다.** 릴리즈 기록이 남긴 문장이 이 자료의 태도와 같습니다 — **「코드도 테스트도 통과하는데 화면이 사실을 말하지 않는다. 그 간극은 열어봐야 보인다.」**

## 4. 🔴 무엇을 막나

- **혼자 하는 폐기** — 사유 · 독립 증인 · 실재 직원 확인. 조정은 여기에 더해 **관리자만**
- **차이를 조용히 지우는 실사** — 증인이 없으면 기록도 남기지 않고 거부하고, 확정하면 경보가 올라갑니다
- **잔량 은폐** — 투여 + 폐기가 불출량을 넘을 수 없습니다. 앰플 부분 사용분이 사라지는 경로를 막습니다
- **이중 불출 · 이중 투여** — 상태를 확인하면서 한 번에 한 번만 넘어갑니다
- **장부가 물리보다 많아지는 것** — 이미 나간 건은 음수로라도 반영하고 경보합니다
- **나가지 않은 보고가 「제출 완료」로 남는 것** — 접수번호가 있어야 접수된 것입니다
- **막지 않는 것** — 🔴 **반납 경로는 증인을 요구하지 않습니다.** 기관이 운영 규정으로 정할 자리입니다

- 🔴 **실사를 재촉하는 장치는 찾지 못했습니다** — 마지막 실사 시각은 남지만, 주기를 강제하거나 알리는 코드는 이 영역에 없습니다. 실사 주기는 기관의 운영 규정입니다.
