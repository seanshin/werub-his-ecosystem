# 장기이식 — 맞지 않는 장기는 기록부터 막고, 한 기증을 두 번 쓰지 않는다

**Organ transplantation — an incompatible match is stopped before the record is written, and one donation is never used twice**

> **EN** — The transplant module keeps a waitlist, donors, recipient-bound crossmatches, transplant records, rejection events and post-transplant follow-up (HLA typing, immunosuppressant levels, visits). Creating a transplant record runs a compatibility gate that ships **on (block)** and fails closed: the waitlist entry must belong to this recipient, organ types must agree, the donor must be approved, ABO must be compatible using the patient's own blood-typing record first, and the latest crossmatch **for this donor–recipient pair** must be negative and within 30 days. Using the same donor twice is refused **in every mode**. The liver score is calculated only from actual lab results found by LOINC code and is refused when a required result is missing rather than filled in. 🔴 Registration with the national organ-sharing body is **not implemented** — the server path returns a simulated answer and stores nothing — and the graft-survival endpoint returns **fixed example figures, not figures calculated from records**. The web screen is a read-only list. Sits on judgment rules ① honesty, ② single source of truth, ③ guards and ④ gates.

## 1. 무엇을 하나

이식 업무의 기록을 한 곳에 모읍니다.

| 무엇 | 담는 것 |
|---|---|
| 대기자 | 장기 · 혈액형 · 긴급도 · 등록일 · 상태 |
| 기증자 | 생체 · 뇌사 등 기증 형태 · 혈액형 · 장기 · 상태(등록 → 평가 → 승인 → 기증) |
| 교차시험 | 🔴 **기증자와 수혜자를 한 쌍으로 묶은** 결과 · 검사 시각 · 유효기한 |
| 이식 기록 | 수혜자 · 기증자 · 집도의 · 이식일 · 허혈 시간 · 면역억제 요법 |
| 이식 뒤 | 거부반응 · HLA 검사 이력 · 면역억제제 혈중농도(TDM) · 추적관찰 방문 |

🔴 **화면은 읽기 전용 목록입니다.** 기준 커밋의 장기이식 화면은 통계 카드와 대기자 · 기증자 · 이식 기록 목록을 **보여 주기만** 합니다. 등록 · 교차시험 · 이식 기록 · 거부반응 입력은 **서버 경로만 있고 부르는 화면을 찾지 못했습니다.**

## 2. 어떻게 도나

### ① 🔴 이식 기록을 만들 때 — 적합성 게이트

이식 기록을 만드는 순간 아래를 **모두** 봅니다. 걸린 것이 하나라도 있으면 기본 모드에서 **기록을 만들지 않고**, 걸린 사유를 **전부** 돌려줍니다.

| 확인 | 규칙 |
|---|---|
| 대기자 결속 | 대기자 등록이 **이 수혜자의 것**인가 — 다른 환자의 대기 등록을 가져다 쓰지 못합니다 |
| 장기 유형 | 대기 등록 · 기증 · 이식 기록의 장기가 **서로 같은가** |
| 기증자 상태 | **승인** 상태인가 |
| 혈액형(ABO) | 🔴 **환자 본인의 혈액형 원장**을 먼저 씁니다. 원장이 없을 때만 대기 등록 값을 쓰고, 둘이 **다르면 막습니다**. 수혜자 혈액형을 모르거나 기증자 혈액형을 모르면 **막습니다** |
| 교차시험 | 🔴 **이 기증자와 이 수혜자** 사이의 **가장 최근** 교차시험이 **음성**이고 **유효기한 안**인가. 기록이 없으면 막습니다 |

| 모드 | 동작 |
|---|---|
| 차단(**기본**) | 기록을 만들지 않습니다 |
| 경고 | 기록을 만들고, 걸린 사유를 응답에 함께 싣습니다 |
| 끔 | 보지 않습니다 |

- 설정 키는 설정 카탈로그에 **등재돼 있고**, 값이 비었거나 오타면 **차단으로 접힙니다**(fail-closed · [안전 게이트](safety-gates.md)).
- 교차시험 유효기한은 **30일**이고 **코드 고정**입니다.

### ② 🔴 한 기증을 두 번 쓰지 않는다

기록을 만들 때 기증자를 **승인 → 기증 완료로 한 번에 넘기며 선점**합니다. 이미 넘어갔으면 거절합니다. 🔴 **이것은 모드와 무관하게 항상 막습니다** — 게이트를 꺼도 같은 기증자로 두 번째 이식 기록은 생기지 않습니다. 기록 생성 · 대기자 상태 전이 · 기증자 상태 전이는 **한 트랜잭션**입니다.

### ③ 간 점수(MELD) — 실제 검사 결과로만

| 무엇 | 규칙 |
|---|---|
| 입력 | 수혜자의 **최신 검사 결과**를 **LOINC 코드로** 찾습니다(검사 이름으로 찾지 않습니다) |
| 🔴 필수 결과가 없음 | 빌리루빈 · 크레아티닌 · INR 중 하나라도 없으면 **산출을 거부**하고 **무엇이 없는지** 적습니다 |
| 나트륨 | 있으면 **MELD-Na**, 없으면 **MELD** — 🔴 **어느 쪽으로 냈는지를 이름으로** 돌려줍니다 |
| 신선도 | 필수 결과 중 가장 오래된 것이 **7일**을 넘으면 재검 후 재산정 권고를 붙입니다 |
| 검사 시각 | 각 값이 **언제 잰 것인지**를 함께 돌려줍니다 |

- 🔴 **투석 여부를 입력받지 않습니다** — 크레아티닌 상한만 적용합니다.
- 결과는 **돌려주기만 하고 저장하지 않습니다.** 기준 커밋 화면은 이 계산을 부르지 않습니다.
- 🔴 **대기 순서를 정하지 않습니다.** 대기자 목록은 **등록일 순**입니다.

### ④ 이식 뒤의 기록 — 이력으로 남긴다

HLA 검사 · 상세 교차시험 · 면역억제제 혈중농도 · 추적관찰 방문은 **이력으로 저장**합니다. 혈중농도는 목표 범위를 벗어나면 **용량 조정 검토 경고**를 붙입니다.

- 🔴 혈중농도의 **목표 범위를 주지 않으면 5 ~ 15 를 씁니다** — 약물 종류와 **무관한** 기본값입니다.

### ⑤ 통계 카드 — 조회 실패를 「없음」으로 그리지 않는다

대기자 수 · 총 이식 수 · **진행 중인 거부반응**(결과가 없거나 진행 중인 것) · 장기별 대기를 냅니다. 🔴 통계 조회가 실패하면 카드를 지우지 않고 **오류를 보입니다** — 카드가 사라지면 「대기자 · 거부반응 없음」으로 읽히기 때문입니다.

### ⑥ 🔴 대외 등록 — `미구현`

국가 장기이식 관리 기관에 대기자를 등록하는 경로는 **모의 응답**입니다. 등록 번호처럼 보이는 값을 만들어 돌려주지만 **밖으로 나가지 않고 저장도 하지 않습니다.** 대기자 목록의 기관 등록 번호 칸은 **사람이 등록할 때 적어 넣은 값**입니다.

### ⑦ 🔴 이식편 생존율 — 기록에서 계산하지 않는다

생존율 경로는 기준 커밋에서 **고정된 예시 수치**를 돌려줍니다. 이 병원의 이식 기록에서 계산한 값이 **아닙니다.** 기준 커밋 화면은 이 경로를 부르지 않습니다.

## 3. 🔴 왜 그렇게 만들었나

- 🔴 **환자 본인의 혈액형 원장을 먼저 쓰는 이유.** 대기 등록에 적힌 혈액형은 **등록할 때 옮겨 적은 값**입니다. 원장이 있는데 그 값을 믿으면, 옮겨 적기 오류가 **ABO 부적합 이식**으로 이어집니다. 둘이 다르면 어느 쪽이 맞는지 시스템이 고르지 않고 **막습니다**(판정 규칙 ②).
- 🔴 **대기자 결속을 보는 이유.** 코드 주석이 이유를 적고 있습니다 — 결속을 보지 않으면 **다른 환자의 대기 등록 혈액형을 믿고 ABO 부적합을 통과시킬 수 있습니다**(환자 오인).
- 🔴 **교차시험을 쌍으로 묶는 이유.** 기증자에게 붙은 「마지막 교차시험 결과」는 **다른 수혜자와 한 결과**일 수 있습니다. 판정은 **이 쌍의 결과**로만 합니다. 기증자 목록 화면의 교차시험 배지는 **기증자의 마지막 결과**이므로 **수혜자별 판정이 아닙니다.**
- **모르면 막는 이유.** 혈액형을 모르는 것은 「맞다」가 아닙니다(판정 규칙 ①). 게이트 값의 오타가 조용히 끔이 되던 일이 **ABO 부적합 · 과선량 · 2인 확인 같은 치명 통제를 우회**시킨 적이 있어, 모드 해석을 **공용 함수 하나**로 모았습니다(판정 규칙 ④).
- **이중 이식을 모드와 무관하게 막는 이유.** 같은 기증으로 두 기록이 생기는 것은 **정책의 강약이 아니라 사실의 모순**입니다. 선점을 원자적으로 하는 것은 두 단말이 동시에 눌러도 하나만 이기게 하려는 것입니다(판정 규칙 ③).
- 🔴 **간 점수를 실제 결과로만 내는 이유.** 이 계산은 한때 **난수로 만든 모의 값**을 돌려주었습니다. 주석이 그 이유를 적고 있습니다 — **간이식 대기 우선순위를 왜곡하고 안전에 직결**됩니다. 필수 결과가 없으면 **폴백 값으로 채우지 않고 거부**합니다(판정 규칙 ①).
- **검사 이름이 아니라 코드로 찾는 이유.** 이름은 기관마다, 장비마다 다릅니다. 이름으로 찾으면 **다른 검사를 잡습니다**.
- **이식 뒤 기록을 저장하는 이유.** HLA · 혈중농도 · 추적관찰은 한때 **계산한 객체를 돌려주기만 하고 저장하지 않았습니다** — 응답은 기록한 것처럼 돌아오는데 원장에는 남지 않았습니다(판정 규칙 ②).
- **통계 실패를 오류로 보이는 이유.** 사라진 카드는 **0 으로 읽힙니다**(판정 규칙 ①).
- 🔴 **찾지 못한 것** — **교차시험 유효기한 30일**, **간 점수 신선도 7일**, **혈중농도 기본 목표 5 ~ 15** 가 어느 지침에서 온 값인지 기록에서 찾지 못했습니다. 간 점수 공식은 HIS 릴리즈 기록이 **「공식 원문 검증 필요」 목록**에 올려 두었습니다. 🔴 **기관이 관할 규정과 자기 프로토콜로 다시 확인해야 하는 값**입니다.

## 4. 🔴 무엇을 막나

- **다른 환자의 대기 등록으로 이식 기록을 만드는 것** — 대기자 결속
- **장기가 서로 다른 기록** — 대기 · 기증 · 이식의 장기 일치
- **승인되지 않은 기증자** — 기증자 상태
- **ABO 부적합 · 혈액형 미상** — 본인 원장 우선 · 불일치와 미상은 막음
- **다른 쌍의 교차시험을 믿는 것** — 쌍으로 묶은 최신 결과만
- **양성 · 기한 지난 · 없는 교차시험** — 막음
- **한 기증을 두 번 쓰는 것** — 모드와 무관하게 항상
- **부분 저장** — 기록과 상태 전이를 한 트랜잭션으로
- **없는 검사로 간 점수를 만드는 것** — 산출 거부 · 무엇이 없는지 적음
- **통계 조회 실패를 「없음」으로 보이는 것** — 오류 표시
- **막지 못하는 것**
  - 🔴 **국가 기관 등록은 `미구현`입니다** — 모의 응답을 돌려주며 **나가지 않습니다.** 등록은 기관의 기존 절차로 합니다
  - 🔴 **이식편 생존율 경로의 수치는 예시입니다** — 이 병원의 성적으로 **쓰면 안 됩니다**
  - 🔴 **기증자를 평가 · 승인 상태로 넘기는 전용 경로와 화면을 찾지 못했습니다.** 게이트 기본이 차단이므로, 게이트를 켠 채 운영하려면 **승인을 어디서 누가 기록할지** 기관이 먼저 확인해야 합니다
  - 🔴 **이식 기록의 결과 칸은 기본값이 「성공」입니다** — 입력하지 않으면 목록에 성공으로 보입니다. **추적관찰 방문의 이식편 기능 칸도 비우면 「양호」로 저장됩니다**
  - **교차시험 판독은 사람이 합니다** — 시스템은 입력된 결과를 믿고 판정합니다
  - **간 점수는 대기 순서를 정하지 않고, 투석 여부를 반영하지 않습니다**
  - **혈중농도 기본 목표 범위는 약물과 무관합니다** — 약물별 목표는 입력해야 합니다
  - 🔴 **뇌사 판정 · 기증 동의 · 장기 배분 규칙은 이 모듈에 없습니다** — 관할 규정과 기관 절차의 일입니다

- 🔴 **실제 호출로 확인하지 않았습니다.** 새 설치본 따라가기에서 **장기이식 경로를 부르지 않았습니다** — 장기이식 화면은 캡처돼 있으나(가상 병원 데이터 · 목록 화면), 이 글은 기준 커밋 코드를 읽은 것입니다([따라가 본 결과](../../build-guide/follow-along-2026-09.md)).
- 게이트 기본값(**차단**) · 교차시험 유효기한(30일) · 간 점수 신선도(7일) · 혈중농도 기본 목표는 **기준 커밋 코드를 읽은 값**이며 설치본의 **현재** 설정이 아닙니다.
- 장기이식은 HIS 화면의 **특수 치료 다섯 가지** 중 하나로 목록에만 나옵니다. 전용 화면 절은 아직 쓰지 않았습니다.
- 🔴 **이 글은 이식 적합성 기준을 제시하지 않습니다.** 어떤 교차시험 결과를 음성으로 볼지, 유효기한을 얼마로 둘지, 뇌사를 어떻게 판정할지는 **기관과 전문가와 관할 규정이 정할 일**이고, 자료는 **시스템이 무엇을 기록하고 무엇을 막는지**까지만 적습니다.
- 이 기능은 **한 시스템 안**에서 끝나므로 [연결 상태 표](../../RELEASES/2026.09/compatibility.md)에는 나오지 않습니다. 국가 기관 등록은 바깥 연결이지만 `미구현`입니다.
