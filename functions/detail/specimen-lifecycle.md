# 검체 — 「이 검체로는 못 낸다」를 말하는 자리

**Specimens — where the system says "this sample cannot answer that test"**

> **EN** — A specimen moves through seven states from collection to disposal, and a rejection always carries a coded reason. Beyond accept/reject there is a middle ground the design takes seriously: a sample that is usable for some tests and misleading for others. Haemolysis, icterus and lipaemia are graded, and a grade of 2+ or higher raises an interference warning **on the specific tests that factor distorts** — potassium and LDH for haemolysis, for example. The shipped table is explicitly a **starter rule**: which analytes are affected, and at what threshold, is something each laboratory must confirm for its own instruments and reagents, and **the decision to redraw stays with a person**. Instrument results arrive as ASTM E1394 or CSV over an HTTP endpoint and converge on the **same pipeline as manually entered results**; unmapped instrument codes are skipped with a recorded reason rather than guessed. The low-level instrument transport (serial / TCP) is **not implemented** — an institution puts a relay in front of it. Sits on judgment rules ① honesty, ② single source of truth and ⑥ people decide.

## 1. 무엇을 하나

검사는 검체가 있어야 시작됩니다. 그런데 검체는 **있거나 없는 것**이 아니라 **쓸 만하거나 아닌 것**이고, 더 정확히는 **어떤 검사에는 쓸 만하고 어떤 검사에는 아닌 것**입니다.

이 생태계가 검체에 대해 하는 일은 넷입니다.

| 무엇 | 왜 |
|---|---|
| **생명주기를 상태로 관리** | 지금 이 검체가 어디 있는지 |
| **라벨** | 사람이 손으로 옮겨 적지 않게 |
| **품질 등급** | 🔴 「이 검체로는 이 검사를 못 낸다」를 말하려고 |
| **결과 수집** | 장비에서 오든 사람이 넣든 **같은 파이프라인으로** |

## 2. 어떻게 도나

### ① 생명주기 — 일곱 상태, 그리고 거부에는 항상 사유 코드

**채취 → 접수 → 검사 중 → 완료**가 본줄기이고, 옆으로 **거부 · 보관 · 폐기**가 있습니다.

거부는 사유가 **코드로** 남습니다 — 용혈 · 양 부족 · 응고 · 오염 · 그 밖. 거부 시각도 함께 남습니다.

→ 사유를 자유 문장으로만 받으면 **「왜 거부가 늘었나」를 나중에 셀 수 없습니다.** 코드로 남겨야 채취 교육이 필요한 병동, 용기가 잘못 나간 검사, 이송이 느린 구간이 드러납니다.

### ② 라벨 — 바코드는 만들고, 보내는 것은 앞단이 한다

검체 번호를 **Code128 바코드**로 담고 환자 이름·번호·검사 요약·채취 시각을 얹은 라벨 데이터를 만듭니다.

🔴 **라벨에 들어가는 글자에서 프린터 제어 문자를 지웁니다.** 환자 이름이나 검사명에 제어 문자가 섞여 들어오면 **라벨의 다른 칸이 망가지거나 원하지 않는 명령이 프린터로 갑니다.** 길이도 잘라 냅니다.

만든 데이터를 프린터로 **보내는 것은 앞단(화면 · 인쇄 큐)의 일**입니다. 🔴 **네트워크로 연결된 라벨 프린터만 실제 전송이 됩니다** — 자세한 것은 [LIS 구성서](../../systems/lis.md)를 보십시오.

### ③ 품질 등급(HIL) — 🔴 거부와 통과 사이

| 축 | 무엇 | 등급 |
|---|---|---|
| 용혈 | 적혈구가 깨진 정도 | 없음 · 1+ · 2+ · 3+ |
| 황달 | 빌리루빈 | 같음 |
| 지질혈 | 지질 | 같음 |

등급만 적어 두는 것이 아니라 **검사별로** 씁니다. 🔴 **2+ 이상**일 때, **그 인자가 왜곡하는 검사**에만 간섭 경고가 붙습니다 — 예를 들어 용혈은 칼륨 · LDH · AST 를 **거짓으로 높입니다**(깨진 적혈구에서 칼륨이 나오기 때문입니다). 경고 문구는 「간섭 가능 — 재채취 검토」까지입니다.

🔴 **이 표는 「스타터 규칙」이라고 코드가 스스로 적습니다.** 어떤 검사가 어느 인자에 영향을 받는지, 임계를 어디로 둘지는 **장비와 시약에 따라 달라서 검사실이 확정해야 하는 값**입니다. 그리고 **재채취할지 말지는 사람이 정합니다** — 시스템은 「이 값이 왜곡될 수 있다」까지만 말합니다.

→ 기관이 할 일: 자기 장비·시약 기준으로 **영향 검사와 임계를 다시 정하십시오.** 그대로 쓰면 **자기 검사실의 규칙이 아니라 예시 규칙**으로 도는 것입니다.

### ④ 결과 수집 — 어디서 오든 **한 파이프라인으로 모인다**

| 경로 | 무엇 |
|---|---|
| 장비 | ASTM E1394 레코드 또는 계기 CSV **원문을 본문에 담아** 수집 끝점으로 보냅니다 |
| 사람 | 화면에서 값을 넣습니다 |
| 문서 | 비협조 장비의 원본 리포트 · 외부 검사 결과지 · 슬라이드 이미지를 **첨부**합니다 |

세 경로가 **같은 곳으로 수렴합니다** — 장비코드 매핑 → 자동 평가 → **2차 검증**([검사 결과 검증](result-verification.md)). 🔴 **장비에서 왔다는 이유로 검증을 건너뛰지 않습니다.**

**매핑이 없으면 추측하지 않습니다.**

| 상황 | 결과 |
|---|---|
| 장비코드가 매핑에 없음 | 🔴 **건너뛰고 「매핑 미등록」을 사유로 남깁니다** |
| 검체가 없거나 수집이 실패 | 건너뛰고 사유를 남깁니다 |
| 나머지 | 수집합니다 — **부분 성공을 허용합니다** |

한 묶음이 통째로 실패하지 않는 대신, **무엇이 들어왔고 무엇이 왜 빠졌는지**가 요약으로 돌아옵니다.

**원문은 통신 로그에 보존**됩니다(장애 조사·재처리용). 🔴 다만 **로그 목록 API 는 원문을 싣지 않습니다** — 원문에는 환자 식별자와 검사값이 통째로 들어 있는데, 이 API 의 권한은 마스터 조회라 **임상 결과 열람 권한과 등급이 다르기** 때문입니다. 원문이 필요한 조사는 권한이 다른 연계 콘솔로 갑니다.

### ⑤ 🔴 장비와 직접 말하지는 못한다

파서와 수집 끝점은 있지만, **장비의 저수준 전송(직렬 · TCP)을 받는 부분은 `미구현`**입니다. 기관은 **장비와 LIS 사이에 중계 장치를 두거나**, 결과 파일 입력 · 수기 입력으로 운영합니다([LIS 구성서 §10](../../systems/lis.md)).

→ 즉 **「장비를 꽂으면 결과가 들어온다」가 아닙니다.** 중계를 누가 만들고 누가 유지하는지가 **기관의 구축 항목**입니다.

## 3. 🔴 왜 그렇게 만들었나

- **거부 사유를 코드로 받은 이유** — 자유 문장은 나중에 셀 수 없습니다. 무엇을 고쳐야 하는지는 **분류된 수**에서 나옵니다(판정 규칙 ⑦).
- **HIL 을 검사별로 붙인 이유** — 검체 전체를 「불량」으로 처리하면 **멀쩡히 낼 수 있는 검사까지 버립니다.** 반대로 아무 말도 안 하면 **왜곡된 값이 정상값처럼** 나갑니다. 그래서 **영향받는 검사에만** 경고를 붙입니다.
- **스타터 규칙이라고 못 박은 이유** — 간섭 임계는 장비·시약마다 다릅니다. 예시 값을 「우리 규칙」처럼 쓰면 **자기 검사실에서 틀린 경고와 틀린 침묵**이 동시에 생깁니다(판정 규칙 ②).
- **재채취를 시스템이 정하지 않는 이유** — 재채취는 환자에게 바늘을 한 번 더 꽂는 일입니다. 이 자료의 일관된 태도대로, 시스템은 **근거를 보여 주고 사람이 정합니다**(판정 규칙 ⑥).
- **세 경로를 한 파이프라인으로 모은 이유** — 장비 경로만 검증을 건너뛰면 **검증 규칙이 둘**이 됩니다. 비협조 장비가 있는 한 수기·문서 경로는 **영구히 병존한다**고 코드가 적고 있습니다.
- **매핑 없는 코드를 추측하지 않는 이유** — 비슷한 이름에 붙이면 **다른 검사의 값이 됩니다.** 건너뛰고 사유를 남기는 편이 안전합니다(판정 규칙 ①).
- **통신 로그 목록에서 원문을 뺀 이유** — 권한 등급이 다른 API 로 **환자 식별자와 결과값이 통째로 나가는 것**을 막으려는 것입니다(판정 규칙 ⑤).
- 🔴 **찾지 못한 것** — 거부 사유 코드 다섯 가지를 **어느 기준(인증·지침)에서 가져왔는지**는 기록에서 찾지 못했습니다.

## 4. 🔴 무엇을 막나

- **거부 사유를 자유 문장으로 흘리는 것** — 코드로 남깁니다
- **라벨 데이터에 섞인 제어 문자가 프린터로 나가는 것** — 지우고 길이를 자릅니다
- **검체 하나를 통째로 「불량」으로 버리는 것** — 영향받는 검사에만 경고합니다
- **왜곡된 값을 정상값처럼 내보내는 것** — 2+ 이상이면 그 검사에 경고가 붙습니다
- **예시 규칙을 자기 규칙처럼 쓰는 것** — 코드가 「스타터」임을 밝힙니다
- **시스템이 재채취를 결정하는 것** — 「간섭 가능 · 검토」까지만 말합니다
- **장비에서 왔다고 검증을 건너뛰는 것** — 세 경로가 같은 파이프라인으로 수렴합니다
- **모르는 장비코드를 비슷한 검사에 붙이는 것** — 건너뛰고 사유를 남깁니다
- **한 건 실패로 묶음 전체를 잃는 것** — 부분 성공을 허용하고 요약으로 말합니다
- **권한 등급이 낮은 API 로 원문이 나가는 것** — 로그 목록에서 원문을 뺍니다
- **막지 못하는 것** — 🔴 **장비와 직접 말하지 못합니다**(저수준 전송 `미구현`). 중계를 두는 것은 기관의 일입니다
