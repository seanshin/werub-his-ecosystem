## ① · ② MIT — 쓰고, 고치고, 다시 배포할 수 있게

MIT 는 "있는 그대로(AS IS) · 무보증"으로 제공하고, 사본에 저작권 고지와 허가 고지를 포함하라고 적는 짧은 라이선스입니다. 이 저장소는 MIT 입니다.

**소스 저장소의 표기는 아직 정리 중입니다.** 매니페스트는 각 소스 저장소가 기준 커밋에서 스스로 적은 표기를 그대로 싣습니다.

| 저장소 라이선스 표기(기준 커밋) | 시스템 |
|---|---|
| 독점 | HIS · 공개 홈페이지 · 환자 앱 · PACS · AI Server · edu · Clinic |
| UNLICENSED(비공개 선언) | sign |
| 독점 · UNLICENSED 혼재 | LIS |
| 표기 없음 | ERP · twin · cerno · Jitsi |

근거: [매니페스트](../RELEASES/draft/manifest.md) 「저장소 라이선스 표기」 칸(계측일 2026-09-11 · 한 저장소에 표기가 여럿이면 매니페스트는 모두 적습니다). 각 시스템의 소스 링크도 아직 "정리 중"입니다. **소스를 받을 때는 그 저장소에 적힌 표기를 확인하세요.** 표기가 정리되는 대로 매니페스트를 갱신합니다.

## 의료 면책 — 다섯 가지

[DISCLAIMER.md](../DISCLAIMER.md)의 요지입니다.

1. **의료기기가 아닙니다.** 어느 국가에서도 의료기기(SaMD 포함)로 인허가를 받지 않았습니다.
2. **적합성 판단과 인허가는 구축 기관의 책임입니다.** 임상에 쓸지, 어느 범위에서 쓸지, 의료기기 해당성 검토 · 규제 인허가 · 개인정보 · 의료법상 의무 이행 모두 도입 기관의 몫입니다.
3. **AI 산출물은 보조 정보입니다.** AI 는 진단 · 처방을 확정하지 않고 초안과 제안을 만들 뿐이며, 권한 있는 사람이 승인해야 정본이 됩니다.
4. **데모 데이터는 가상입니다.** 실존하는 기관이나 사람과 관계가 없습니다.
5. **구현 상태는 기준 버전에서의 사실입니다.** 다른 버전에서는 사실이 다를 수 있습니다.

**규제 표기의 세 단계** — 이 자료는 규제 항목을 `대응 설계` · `자체 점검 완료` · `외부 인증·승인`(증빙 번호가 있을 때만) 세 단계로만 적습니다. "인증 · 준수"라는 말은 셋째 단계에서만 씁니다. 시스템 구성서가 적은 규제 관련 항목(예: HIS 의 전자의무기록 인증 준비 관리 화면 · 개인식별정보 암호화와 열람 감사 · sign 의 인증 기준 대응표 · AI Server 의 디지털의료기기 가이드라인 대응 체계)은 모두 **`대응 설계`** 이고, `자체 점검 완료` · `외부 인증·승인`으로 적힌 항목은 없습니다([시스템 구성서](../systems/) 각 장의 「표준과 규제」 · 2026-09-11 작성 기준).

## ③ MIT 가 덮지 않는 것

### 별도 서비스로 쓰는 제3자 서버

생태계 코드는 데이터베이스 · 캐시 · 영상 서버 · 관측 · BI · 화상 회의 · PDF 렌더 · 모델 서버를 **자기 코드에 링크하거나 섞지 않고**, 공식 이미지 · 설치본을 별도 컨테이너나 별도 프로세스로 띄워 네트워크 프로토콜로 부릅니다([THIRD_PARTY §5](../THIRD_PARTY.md#5-구조--링크하지-않고-별도-컨테이너로-씁니다)). 이 구조가 각 라이선스에서 어떤 의미인지는 THIRD_PARTY 도 판단하지 않습니다. 조건이 두드러진 것은 이렇습니다.

| 구성요소 | 원문이 적은 사실 | 구축 기관 · 법무가 확인할 것 |
|---|---|---|
| Grafana · Metabase · Orthanc 플러그인(DICOMweb · PostgreSQL) | AGPL-3.0 계열입니다. AGPL 제13조는 수정본을 네트워크로 사용자에게 제공하는 경우를 다룹니다 | 수정 여부 · 외부 사용자에게 제공하는지 |
| Orthanc 코어(PACS 영상 서버) | GPL-3.0-or-later 입니다 | 이미지를 재배포하거나 수정하는지 |
| **Redis 7** | **7.4.x 부터 RSALv2 또는 SSPLv1 중 선택**입니다. 7.2 이하는 BSD-3-Clause 입니다. 저장소의 `7-alpine` 태그는 기준일(2026-09-11)에 7.4.11 을 받습니다 | 실제 받은 버전 · 어느 약관을 고를지 |
| browserless(v1 이미지 · HIS 서버 PDF 렌더) | GPL-3.0-or-later 또는 상용 라이선스입니다. v1 README 는 폐쇄 소스 상업 용도에 상용 라이선스가 필요하다고 적습니다 | 쓰는 용도 · 대체 수단 |

특히 다음 경우는 따로 확인합니다 — ① 제3자 서버를 **수정해서** 쓰는 경우 ② 원내 직원이 아닌 **외부 사용자에게 네트워크로 제공**하는 경우 ③ 이미지나 빌드 산출물을 **다른 기관에 재배포**하는 경우 ④ `메이저만 고정` · `고정 안 됨` 태그처럼 **받는 날에 따라 판본이 바뀌는** 구성요소.

### 소스를 가져와 고친 제3자 코드

PACS 웹 뷰어는 OHIF Viewer 와 Cornerstone3D(둘 다 MIT)를 받아 함께 빌드합니다. MIT 는 원 저작권 고지와 허가 고지를 포함하라고 적습니다. 빌드 산출물에 묶이는 나머지 npm 패키지의 고지 목록은 아직 만들지 않았으므로, 뷰어를 다시 빌드하거나 배포하는 기관은 따로 확인합니다([THIRD_PARTY §2](../THIRD_PARTY.md#2-소스를-가져와-고친-제3자-코드)).

### AI 모델 가중치

이 저장소에도 생태계 소스에도 들어 있지 않고, 기관이 모델마다 약관을 읽고 직접 받습니다 → [6장](06-ai.md#모델은-기관이-골라서-직접-받습니다).

- **MedGemma 계열(HAI-DEF 약관)** — 임상 사용(환자의 진단 · 치료에 쓰는 것, 연구 포함)에 해당하면 관할 규제 기관의 승인을 받으라고 적습니다. 금지 사용 정책도 약관에 포함됩니다.
- **Llama 계열 파생 모델(Med42 · Meditron)** — Llama 3 / Llama 2 Community License 입니다. 배포할 때의 표시 요건이 있고, 개발사 모델 카드는 추가 검증 없이 임상에 쓰지 말라고 경고합니다.
- **커뮤니티 재포장 태그** — 원 개발사가 아닌 제3자가 올린 태그는 가중치와 약관이 원본과 같은지 기관이 확인합니다.
- 코드에 선택지로만 등록된 의료 모델은 기본 경로가 아니며, 대부분 원문을 보지 않았습니다(`확인 필요`). 켜기 전에 약관을 따로 확인합니다.

### 코드 마스터 · 기준 데이터

이 저장소는 담지 않습니다. 구축 기관이 배포 기관에서 직접 받아 반입합니다([THIRD_PARTY §4](../THIRD_PARTY.md#4-코드-마스터기준-데이터)).
