# PACS → 외부 PACS

> 연동 계약 카드 — [카드 목록](README.md) · [연동 지도](../README.md) · 상태의 정본은 [연결 상태 표](../../RELEASES/2026.09/compatibility.md)입니다.

> **EN** — Integration contract card: **PACS → 외부 PACS**. None of these 1 have been called end to end yet — they are wired in code only. Config keys are listed by **name only** — values are generated by the institution. Authoritative status lives in the [connection table](../../RELEASES/2026.09/compatibility.md).

**무엇을 주고받나** — 다른 기관이나 다른 PACS 와 영상을 주고받는 경로입니다(조회 · 가져오기 · 보내기). 상대 노드를 관리 화면에 미리 등록해 두고 씁니다.

## 연결

| 목적 | 프로토콜 | 인증 | 상태 | 확인일 |
|---|---|---|---|---|
| 원격 DICOM 노드 조회·가져오기·보내기(C-ECHO/C-FIND/C-MOVE/C-STORE) | DICOM DIMSE(Orthanc 경유) | AE 타이틀·원격 노드 등록(관리자) | `구현·미검증` | — |

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `PACS: 원격 노드 등록(관리 화면 /api/v1/remotes)`

## 여는 순서

1. 상대 노드의 **이름표 · 주소 · 포트**를 관리 화면에 등록하고, 상대에게도 이쪽 값을 등록해 달라고 요청합니다.
2. 연결만 먼저 확인합니다(에코).
3. 조회 → 가져오기 → 보내기 순으로 하나씩 확인합니다.
4. 🔴 **밖으로 나가는 경로**입니다. 어느 기관에 무엇을 보낼 수 있는지, 환자 동의는 어떻게 받는지를 기관 규정으로 먼저 정하십시오.
5. 확인만 하려면 같은 이미지로 PACS 를 **하나 더 세워** 상대 역할을 시키면 됩니다 — 외부 기관이 필요 없습니다.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
