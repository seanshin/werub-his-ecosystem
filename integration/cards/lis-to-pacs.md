# LIS → PACS

> 연동 계약 카드 — [카드 목록](README.md) · [연동 지도](../README.md) · 상태의 정본은 [연결 상태 표](../../RELEASES/2026.09/compatibility.md)입니다.

> **EN** — Integration contract card: **LIS → PACS**. 2 of 2 verified by real calls (dates in the table below); the rest are wired in code but not yet called. Config keys are listed by **name only** — values are generated by the institution. Authoritative status lives in the [connection table](../../RELEASES/2026.09/compatibility.md).

**무엇을 주고받나** — 병리 슬라이드를 스캔할 목록을 LIS 가 PACS 에 올리고(취소도 같은 경로), 스캔된 영상이 실제로 도착했는지 확인해 뷰어 링크를 엽니다. 목록 등록·취소는 HL7 v2 메시지를 TCP 로 직접 보내고, 영상 도착 확인과 뷰어 링크는 PACS 의 REST·DICOMweb 으로 합니다. 열람했다는 사실은 LIS 쪽에 기록으로 남습니다.

## 연결

| 목적 | 프로토콜 | 인증 | 상태 | 확인일 |
|---|---|---|---|---|
| 병리 슬라이드 스캔 워크리스트 등록·취소(ORM^O01 NW/CA → PACS worklist → MWL) | HL7 v2.3 ORM^O01 over MLLP(TCP) | 없음(MLLP) · PACS 선택 게이트 HL7_ALLOWED_PEERS(소스 IP | `검증됨` | 2026-09-15 |
| 병리 WSI 뷰어 링크 해소 · QIDO 로 영상 도착 확인 · 열람 확인 기록 | HTTPS REST(PACS 로그인) + DICOMweb QIDO-RS + 뷰어 런 | PACS 로컬 서비스 계정 로그인 → PACS JWT | `검증됨` | 2026-09-15 |

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `LIS: PACS_MLLP_HOST`
- `LIS: PACS_MLLP_PORT`
- `PACS: HL7_BIND`
- `PACS: HL7_PORT`
- `PACS: HL7_ALLOWED_PEERS`
- `PACS: HL7_ALLOWED_FACILITIES`
- `LIS: PACS_BASE`
- `LIS: PACS_USER`
- `LIS: PACS_PASS`

## 여는 순서

1. PACS 의 HL7 수신기를 켜고, **어느 주소에서 오는 메시지를 받을지 · 어느 기관·응용 이름을 받을지** 허용 목록에 적습니다. 비워 두면 수신기가 누구에게나 열립니다.
2. LIS 에 PACS 의 HL7 수신 주소와 포트를 넣습니다. 이 통신에는 계정·비밀번호가 없으므로 **격리된 망 안**에 두고 위 허용 목록으로 좁히는 것이 사실상 유일한 경계입니다.
3. PACS 에 LIS 전용 서비스 계정을 하나 만들고(영상 조회 권한), LIS 에 그 계정을 넣습니다. 뷰어 링크와 도착 확인은 이 계정으로 합니다.
4. 병리 오더 하나로 끝까지 해 봅니다 — 목록 등록 → 스캐너가 영상 저장 → LIS 에서 도착 확인 → 뷰어 링크 열기.
5. 🔴 HIS 가 내려보내는 검사 코드 마스터에 **병리 항목이 없으면 이 흐름은 시작되지 않습니다**. 코드 마스터에 병리 코드가 있는지 먼저 확인하십시오.
