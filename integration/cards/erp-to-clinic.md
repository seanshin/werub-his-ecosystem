**무엇을 주고받나** — ERP 가 그룹웨어의 직원 명단을 하루 한 번 받아 인사 정보와 맞춰 보고, 그룹웨어 사용자와 ERP 직원을 이어 둡니다. 출퇴근 기록을 받아 월 근태 집계에 넣는 경로는 **아직 없습니다**(한쪽 코드가 비어 있습니다).

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `erp: clinic_api_base`
- `erp: clinic_api_key`
- `erp: hospital_code`
- `clinic: HIS API 키(관리 화면 발급)`

## 여는 순서

1. 그룹웨어 관리 화면에서 ERP 용 API 키를 발급하고 **직원 조회 권한**을 줍니다.
2. ERP 에 그룹웨어 주소 · 그 키 · 기관 코드를 넣습니다. 세 값이 한 벌로 움직입니다.
3. 수집을 한 번 손으로 돌려 **이어 붙지 않은 직원이 몇 명인지** 봅니다. 여기서 남는 것이 대개 이름·이메일 표기 차이입니다.
4. 차이를 정리한 뒤 정해진 시각의 자동 수집을 켭니다.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
