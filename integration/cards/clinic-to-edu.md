> **EN** — Integration contract card: **Clinic → edu**. None of these 1 have been called end to end yet — they are wired in code only. Config keys are listed by **name only** — values are generated by the institution. Authoritative status lives in the [connection table](../../RELEASES/draft/compatibility.md).

**무엇을 주고받나** — 그룹웨어에 로그인한 사용자가 edu 로 들어갈 때 다시 로그인하지 않게 하는 딥링크입니다. 그룹웨어가 수명 짧은 토큰을 만들어 붙이고 edu 가 **공유 비밀**로 검증합니다 — HIS 진입(공개키 방식)과 검증 방식이 다릅니다.

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `EDU_URL`
- `EDU_SSO_LANDING`
- `EDU_SSO_SECRET`
- `EDU_SSO_DEFAULT_ROLE`
- `HIS_JWT_SECRET(edu: his.jwtSecret)`

## 여는 순서

1. 양쪽에 같은 공유 비밀을 넣습니다. HIS 진입에 쓰는 값과 **섞지 마십시오** — 방식이 다릅니다.
2. 그룹웨어에 edu 주소와 도착 화면을 넣습니다.
3. 처음 들어온 사용자에게 줄 **기본 역할**을 정합니다. 기본값을 그대로 두면 들어온 사람이 모두 같은 역할이 됩니다.
4. 사용자 한 명으로 눌러 봅니다. 🔴 토큰 수명이 매우 짧아 **시계가 어긋나면 바로 실패**합니다.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
