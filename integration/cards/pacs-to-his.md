# PACS → HIS

> 연동 계약 카드 — [카드 목록](README.md) · [연동 지도](../README.md) · 상태의 정본은 [연결 상태 표](../../RELEASES/2026.09/compatibility.md)입니다.

> **EN** — Integration contract card: **PACS → HIS**. None of these 3 have been called end to end yet — they are wired in code only. Config keys are listed by **name only** — values are generated by the institution. Authoritative status lives in the [connection table](../../RELEASES/2026.09/compatibility.md).

**무엇을 주고받나** — PACS 가 판독 결과를 HIS 차트에 반영하고, 촬영 목록을 맞추려고 HIS 의 영상 오더를 읽습니다. 두 경로 모두 REST 가 아니라 **HIS 데이터베이스에 직접 접속**합니다. 판독 결과를 HL7 로 보내는 표준 경로는 아직 없습니다.

## 연결

| 목적 | 프로토콜 | 인증 | 상태 | 확인일 |
|---|---|---|---|---|
| 판독 결과 반영 — PACS 가 HIS DB 에 imaging_results UPSERT + orders.status=COMPLETED 직접 쓰기 | PostgreSQL 직접 접속(SQL) | DB 계정(접속 문자열이 PACS 코드 상수) | `구현·미검증` | — |
| 영상 오더 → PACS 워크리스트 동기화(HIS DB 읽기 전용 · 관리자 온디맨드) · 환자 병합 재조정 | PostgreSQL 직접 접속(읽기) | DB 계정 | `구현·미검증` | — |
| 판독 결과 HL7 ORU^R01 송신 | HL7 v2 over MLLP | 없음 | `미구현` | — |

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `PACS: 설정 키 없음 — hospitalrun_sync.py 의 코드 상수 HR_DB_URL`
- `PACS: HOSPITALRUN_DB_URL(비우면 비활성)`

## 여는 순서

1. 🔴 이 방향은 **HIS DB 계정**이 있어야 합니다. 읽기 전용(오더 동기화)과 제한 쓰기(판독 반영)를 **따로** 만들고, 실제로 쓰는 표에만 권한을 줍니다.
2. 읽기 경로는 PACS 설정에 접속 문자열을 넣으면 켜지고, **비우면 꺼집니다**.
3. 🔴 쓰기 경로의 접속 문자열은 설정 값이 아니라 **코드에 박혀 있습니다** — 기관 값으로 바꾸려면 코드를 고쳐야 합니다. 두 프로젝트와 협의하십시오.
4. DB 직접 접속은 HIS 의 권한 검사와 감사 기록을 **지나지 않습니다**. 계정 권한을 최소로 하고, 접속 출발지를 제한하고, DB 쪽 감사를 켜 두십시오.
5. 판독 하나로 끝까지 — 촬영 → 판독 작성 → HIS 차트 반영 · 오더 상태 변경.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
