> **EN** — Integration contract card: **PACS → AI Server**. None of these 2 have been called end to end yet — they are wired in code only. Config keys are listed by **name only** — values are generated by the institution. Authoritative status lives in the [connection table](../../RELEASES/2026.09/compatibility.md).

**무엇을 주고받나** — PACS 가 영상 판독 보조 · 사전 점검 · 비교 판독 · 구조화 판독문 **초안**을 AI 서버에 맡기고, 텍스트 요약과 코드 매핑도 같은 경로로 부릅니다. AI 서버가 살아 있는지 주기적으로 확인하는 경로는 지금 맞물려 있지 않습니다.

## 연결

| 목적 | 프로토콜 | 인증 | 상태 | 확인일 |
|---|---|---|---|---|
| 영상 AI 보조(판독 보조·사전점검·비교 판독·구조화 판독문) · 텍스트 보조(요약·분석·설명·초안·참고·자동기록) · 예측·코드매핑 · 오케스트레이션 파이프라인 | HTTPS REST(JSON · multipart) | Bearer(ai_api_key). ai_advanced 의 기본 헤더만 X-Med | `구현·미검증` | — |
| AI 서버 가용성 감시(30분 주기 프로브 · 상태 전이 알림) | HTTPS GET /api/tags | 없음(코드 주석: '인증 불요') | `미구현` | — |

## 양쪽에 넣는 설정 — **키 이름만**

값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

- `ai_server_url`
- `ai_api_key`
- `ai_medical_key`
- `screening_enabled`

## 여는 순서

1. PACS 관리 설정에 AI 서버 주소와 키를 넣습니다. 스킬 묶음마다 **보내는 헤더가 달라서** 두 종류 키를 모두 채워 두는 편이 안전합니다.
2. 사전 점검 기능에는 따로 스위치가 있습니다 — 켤지 정합니다.
3. 영상 한 건으로 확인합니다: 판독 보조 요청 → 초안 수신. 🔴 **초안은 판독이 아닙니다** — 판독의가 고쳐 서명해야 판독이 됩니다.
4. 가용성 감시는 `미구현` 입니다. 상태 표시에 기대지 말고 **AI 서버 쪽에서 직접** 확인하십시오.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
