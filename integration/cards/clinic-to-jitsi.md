값은 기관이 새로 만듭니다. 이 자료는 값을 담지 않습니다.

## 여는 순서

1. 화상 서버를 새로 세운 뒤 관리 API 키를 발급해 그룹웨어에 넣습니다.
2. 이쪽은 **서버 간 호출**이라 키가 브라우저로 내려가지 않습니다 — 앞 카드와 달리 관리 권한 키를 써도 됩니다.
3. 회의 한 건으로 녹화 시작 · 종료 · 목록을 확인합니다.

## 따라가기에서 확인한 것

이 방향은 **아직 실제로 불러 보지 않았습니다.** 상태는 양쪽 코드를 대조한 판정입니다.
