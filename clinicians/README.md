# 진료하는 사람을 위한 안내

**For clinicians — what changes at the bedside**

> **EN** — Written for the people who actually use this system in care: physicians, nurses, laboratory technologists, radiological technologists and pharmacists. It answers five questions: what changes in my work, what the AI does and does **not** do, what the system deliberately blocks, what I must approve and where my name is recorded, and what to do when something is not available. **This is guidance for using the system, not clinical guidance** — it prescribes no drug, dose or reading criterion. Every statement points to a screen, a system brief or the connection table; where something has not been verified, it says so.

> 🔴 **이 문서는 진료 지침이 아닙니다.** 시스템을 쓰는 방법과 한계를 적은 것입니다. 약물 · 용량 · 판독 기준을 이 자료가 제시하지 않습니다.
> 🟡 **초안** — 시스템 담당의 확인 전입니다. 상태는 [연결 상태 표](../RELEASES/2026.09/compatibility.md)가 정본입니다.

## 1. 다섯 줄 요약

1. **AI 는 초안까지입니다.** 사람이 승인해야 기록이 됩니다. 승인 이력이 남습니다.
2. **막히는 것이 고장이 아닙니다.** 이 시스템은 값이 모자라거나 확인되지 않으면 **일부러 멈춥니다**.
3. **화면이 "모른다"고 말합니다.** 0 이라고 안전하다는 뜻이 아닙니다 — 아홉 가지 방식으로 구분해 적습니다.
4. **내 이름이 남는 자리**가 정해져 있습니다(서명 · 검증 · 판독 · 투약 · 승인).
5. **아직 안 되는 것**이 있습니다. 그때 무엇으로 대신하는지도 함께 적었습니다.

## 2. AI 가 하는 일과 **하지 않는 일**

**하는 일** — 증상 분류 보조 · 진료 기록 초안(대화 · 음성) · 환자용 약물 설명과 검진 결과 설명 초안 · 근거 문서 질의 · 약물 상호작용 점검 보조 · 위험 점수 카드 · 화면 번역.

🔴 **하지 않는 일**

| 하지 않는 것 | 어떻게 보장되나 |
|---|---|
| **진단하지 않습니다 · 판단하지 않습니다** | 자료와 화면의 표기 규칙입니다. AI 산출물은 **초안**이고, 사람이 승인해야 진료기록이 됩니다 |
| **내 이름으로 몰래 기록하지 않습니다** | AI 제안 원장에 생성 → 승인 · 수정 · 거부가 남고, 환자를 지목한 AI 조회는 감사 기록에 남습니다 |
| **환자 정보를 밖으로 보내지 않습니다** | 의료 · 개인건강정보 작업을 외부 AI 제공자로 보내지 않도록 코드가 막습니다. 목적지 허용 목록이 비어 있으면 외부로 나가지 않습니다 |
| **모델이 병원 안에 있습니다** | 연산은 기관 안 [AI Server](../systems/ai-server.md)에서 합니다. HIS 에는 모델이 없습니다 |

**AI 가 멈추면** — 화면이 그 칸을 「폴백」 또는 「산출 불가」로 표시합니다. **빈칸으로 두지 않습니다.**

🔴 **기관이 정하는 것** — AI 기능 전체 스위치는 코드 기본값이 **켜짐**입니다. 생태계 원칙은 **설치 직후 끄고 기관 결정으로 하나씩 켜는 것**입니다([S6](../build-guide/S6-ai.md)). 어떤 기능이 켜져 있는지는 병원마다 다릅니다 — **내 화면에 보이는 것이 곧 이 시스템의 전부가 아닙니다.**

## 3. 시스템이 **일부러 막는 것**

막히면 대개 설정이 덜 된 것이 아니라 **그렇게 만든 것**입니다.

| 무엇을 막나 | 왜 |
|---|---|
| 같은 사람이 입력하고 검증하는 것 | 입력자와 검증자가 같으면 검증이 되지 않습니다(진단검사) |
| 참고치·단위가 없는 결과의 자동 확정 | 비교 기준이 없으면 자동으로 확정하지 않습니다 |
| 동의 없는 다음 단계 | 수혈 출고 전 동의 상태 확인 · 유전체 이차 소견은 **동의가 없으면 건수조차 보여 주지 않습니다** |
| 한 사람이 여는 게이트 | 반사 검사 프로토콜 승인 · 개시 전환은 **두 사람(4-eyes)** 이 필요합니다 |
| 분모 없는 비율 | 표본이 0 이면 비율을 내지 않고 **「산출 불가」**로 적습니다 |
| 시각을 모르는 기록의 봉인 | 추정 시각을 원장에 박지 않습니다 |

🔵 **이 가드는 말로만 있는 것이 아닙니다.** 새로 세운 설치본끼리 실제로 불러 확인한 연결 **27개** 가운데 **23개**는 일부러 결함(위조 서명 · 틀린 키 · 훼손 토큰)을 넣어 **거부되는 것까지** 확인했습니다 → [따라가 본 결과](../build-guide/follow-along-2026-09.md).

## 4. 화면이 **"모른다"고 말하는 자리**

의료인에게 가장 중요한 성질입니다. **0 이 안전을 뜻하지 않습니다.** 같은 0 이라도 왜 0 인지에 따라 화면이 다르게 적습니다.

| 화면이 말하는 것 | 읽는 법 |
|---|---|
| 「표본 0 기준이라 안전을 의미하지 않습니다」 | 잰 대상이 없습니다 |
| 「재지 않았다(0 이 아니다)」 | 계측 자체를 하지 않았습니다 |
| 🔒 「이 계정은 해당 대기열을 조회하지 않습니다(비어 있다는 뜻이 아닙니다)」 | 내 권한 밖입니다 |
| 「아직 계측되지 않습니다 — 위 0건은 '없었다'는 뜻이 아닙니다」 | 계측 미구현입니다 |
| 「여기 없는 통로로 생기는 것은 보이지 않습니다」 | 관측 범위 밖입니다 |
| 「서버가 최근 200건까지만 반환」 | 조회 상한입니다 — 전체는 내보내기로 |
| 🔧 「비어 있는 것은 할 일이 없다는 뜻이 아닙니다」 | 아직 연결되지 않았습니다 |
| 「시각 신뢰 불가 — 추정 봉인 금지」 | 값을 모르면 채우지 않습니다 |
| 「전송 여부 확인 불가」 | 보냈지만 도달을 확인할 수 없습니다 |

전체와 화면 근거: [개요서 2장](../overview/02-principles.md#화면이-모른다고-말하는-아홉-가지-방식).

## 5. **내가 승인해야 하는 것 · 내 이름이 남는 곳**

| 자리 | 무엇이 남나 |
|---|---|
| 전자서명(동의서 · 판독 · 계약 · 이수증) | 서명자 · 인증서 일련번호 · 시각 · 무결성 증거. 나중에 검증 주소에서 문서가 바뀌지 않았음을 확인할 수 있습니다 |
| 오더 · 처방 | 서명 로그가 해시로 이어지고 외부 시점 증거(TSA)로 봉인됩니다 |
| 검사 결과 검증 | 1차 · 2차 검증자가 각각 남습니다 |
| AI 초안 승인 | 생성 → 승인 · 수정 · 거부가 원장에 남습니다 |
| [비상 열람(BTG)](../functions/detail/emergency-access.md) | 열람 사실이 감사 기록에 남습니다 — 🔴 다만 **비상열람 계측은 아직 없습니다**(화면이 그렇게 적습니다) |

## 6. **아직 안 되는 것과 그때 하는 일**

| 안 되는 것 | 그때 |
|---|---|
| 🔴 **대외 기관 전송**(심사평가원 청구 · 법정감염병 신고 등) | 전송 모듈이 구현돼 있지 않습니다. **기존 청구 소프트웨어 · 기존 신고 경로**를 쓰고 그 사실을 기관 문서에 남깁니다 |
| 🔴 **원격 화상(Jitsi)** | 현재 설치본이 동작하지 않습니다(`중단`). 쓰려면 새로 구성해야 합니다 |
| **HIS 화면에서 PACS 영상 열기** | 따라가기에서 끝까지 가지 못했습니다. 그동안 **판독은 PACS 화면에서 직접** 하고, 판독 전자서명은 확인된 경로를 씁니다 |
| **반사 검사(Reflex) 자동 추가** | 완료를 확인하지 못했습니다. 개시 전까지 **사람이 추가 처방**합니다 |
| **수혈 동의 자동 확인** | LIS 화면의 자동 확인까지는 확인하지 못했습니다. **사람이 동의를 확인**하는 절차를 유지합니다(확인되지 않으면 출고가 자동 통과되지 않습니다) |
| **장비 결과 자동 수집** | 직렬·TCP 직결 수집기가 없습니다. 기관이 중계를 두거나 **결과 파일·수기 입력**을 씁니다 |

🔴 **「구현·미검증」은 "동작한다"는 뜻이 아닙니다.** 양쪽 코드가 맞물려 있다는 뜻이고, 우리 병원에서 도는지는 개시 전 리허설에서 확인합니다.
