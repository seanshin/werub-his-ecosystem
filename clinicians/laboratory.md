# 진단검사를 위한 안내

**For laboratory staff**

> **EN** — What changes in the laboratory: receiving orders from the HIS, specimen handling, auto-verification and delta checks, the two-person rules that cannot be bypassed, critical-value closed loop, transfusion and genomics consent gates, and returning results to the chart. It states which links were verified by real calls and which were not, and what to do meanwhile. Not clinical guidance.

> 🔴 **진료 지침이 아닙니다.** · 공통 내용은 [진료하는 사람을 위한 안내](README.md).

## 1. 내 일에서 달라지는 것

| 무엇 | 어떻게 |
|---|---|
| **처방 수신** | HIS 오더가 표준(FHIR)으로 들어옵니다 — 🔵 **실제 호출로 확인됨**(오더 · 취소 전파) |
| **접수 · 라벨** | 바코드 규칙이 서버와 화면에서 같습니다(한쪽만 고치면 어긋나지 않게) |
| **결과 입력** | 장비 결과 파일 · 수기 입력. 🔴 **직렬·TCP 직결 수집기는 없습니다** — 중계를 두거나 파일·수기를 씁니다 |
| **자동 검증** | 참고치 · 델타 체크로 자동 판정하되, **참고치나 단위가 없으면 자동 확정을 막습니다** |
| **2차 검증** | 🔴 **입력자와 검증자가 같으면 검증이 되지 않습니다** |
| **위험치** | 통보 → 상향 → **복창 기록**까지 닫아야 완료됩니다 |
| **결과 회신** | HIS 로 보내면 🔴 **바로 차트에 들어가지 않고** 확인 대기가 됩니다 — 🔵 실제 호출로 확인됨 |
| **청구 캡처** | 확정 수량이 ERP 로 갑니다 — 🔵 실제 호출로 확인됨(접수는 202 · 산정 결과는 조회로 확인) |

## 2. 막히는 자리 — 전부 그렇게 만든 것입니다

| 막히는 것 | 왜 |
|---|---|
| 참고치·단위 없는 결과의 자동 확정 | 비교 기준이 없습니다 |
| 같은 사람의 입력·검증 | 검증이 성립하지 않습니다 |
| 반사 검사 프로토콜의 1인 승인 | **4-eyes** 가 필요합니다 |
| 수혈 출고 전 동의 미확인 | 확인되지 않으면 **자동 통과되지 않습니다** |
| 유전체 이차 소견 | 🔴 **동의가 없으면 건수조차 보여 주지 않습니다** |
| ABO 부적합 | 독립 판정이 따로 막습니다 |

## 3. 0 을 읽는 법

「표본 0 기준이라 안전을 의미하지 않습니다」 · 「재지 않았다(0 이 아니다)」 · 「서버가 최근 200건까지만 반환」(전체는 내보내기).

## 4. 내 이름이 남는 곳

접수 · 결과 입력 · 1차/2차 검증 · 위험치 통보와 복창 · 사인아웃(병리 2단계) · 수혈 시행 2인 확인 · 보고서 서명.

## 5. 아직 안 되는 것

| 안 되는 것 | 그때 |
|---|---|
| **장비 자동 수집** | 중계를 두거나 결과 파일 · 수기 입력 |
| **반사 검사 자동 추가** | 사람이 추가 처방 |
| **수혈 동의 자동 확인** | 사람이 확인(자동 통과되지 않습니다) |
| **조직 게이트 결재 참조** | LIS 관리 화면에서 사람이 기록하는 경로를 씁니다 |
| 🔴 법정감염병 **대외 신고 전송** | 기록은 남지만 전송 모듈이 없습니다 — 기존 신고 경로 |

🔴 **개시 전에 반드시** — HIS 검사코드 카탈로그를 반입하고 코드 매핑을 맞춥니다. 따라가기에서 **HIS 기본 시드 검사 코드 15개 중 LIS 기본 매핑에 있던 것은 3개**였습니다.
