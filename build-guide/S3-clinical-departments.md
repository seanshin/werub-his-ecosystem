# S3 임상 부서 — LIS · PACS · 장비 인터페이스 · 부서별 대외 보고

> ⚠️ 리허설 전 초안 — 새 설치본으로 따라가 보기 전입니다. `확인 필요(따라가기)` 표시는 따라가기에서 확정합니다. · 기준 2026-09-11 · [가이드 목차](README.md)

## ① 목적과 완료 조건

검사(LIS)와 영상(PACS)을 HIS 에 붙이고, 검사 장비 · 영상 장비 · 라벨 프린터를 연결합니다. 이미 쓰는 PACS 가 있으면 표준 프로토콜(DICOM · HL7 v2)로 연결하는 선택도 있습니다. 약제 · 감염관리 · 암등록 · 응급 같은 **부서별 대외 보고**의 준비 상태도 이 단계에서 확인합니다.

완료 조건:

- [ ] LIS 가 설치 · 검증 스크립트를 통과했고, HIS 의 검사 오더를 받아 온다
- [ ] PACS 가 떠 있고, HIS 영상 오더가 PACS 워크리스트에 등록된다
- [ ] 🔴 LIS · PACS 저장소의 **설치본 주소 기본값**을 자기 기관 값으로 바꿨다
- [ ] 🔴 PACS 의 **영상 자동 선별(코드 기본값 켜짐)을 껐다** — 켜는 것은 [S6](S6-ai.md) 결정 뒤
- [ ] 영상 장비가 워크리스트를 조회하고 영상을 보낸다
- [ ] 부서별 대외 보고(마약류 · 감염병 · 암등록 · 진료정보교류 등)의 **대체 경로**를 정했다(전송 모듈 미구현)

## ② 설치

### LIS

| 항목 | 내용 |
|---|---|
| 구현 상태 | `파일럿` |
| 설치 | 준비된 호스트에서 **설치 스크립트 한 번**으로 올라오도록 돼 있습니다(LIS 저장소 `infra/install/install.sh`). 스크립트는 비밀값을 무작위로 만들고, 마이그레이션 적용을 확인하고, 백업 크론을 등록하고, 관리자 초기 비밀번호를 한 번만 출력합니다. 기존 환경 파일이 있으면 덮어쓰지 않고 멈추며, http 주소는 거부합니다 |
| 검증 | 검증 스크립트(`infra/install/verify.sh`)는 "떴다"가 아니라 "쓸 수 있다"를 봅니다(무인증 차단 · API 문서 비노출 · 백업 크론 등록) |
| 시드 | `starter` · `demo` · `all` 중에서 고릅니다. **운영 설치는 `starter`** 이고, 데모 환자 · 데모 계정은 `demo` 에만 있습니다. 시드 프로파일을 지정하는 방법은 `확인 필요(따라가기)` |
| 같은 호스트 | 다른 시스템의 컨테이너가 같은 호스트에 있으면 compose 프로젝트 이름을 고정해 충돌을 막습니다 |

스크립트의 인자와 실행 순서는 LIS 저장소 README 와 설치 문서를 따르고, `확인 필요(따라가기)`.

PACS 저장소 README 의 **Quick Start → Installation** 이 안내하는 명령(기준 커밋 표기):

```sh
cp .env.example .env     # 환경 파일을 만들고 기관 값으로 고칩니다
docker compose up -d     # 전체 서비스 기동
docker compose ps        # 컨테이너 상태 확인
```

뷰어 빌드 · 운영용 설정 · 모니터링 프로필을 포함한 운영 설치 순서는 `확인 필요(따라가기)`.

### 장비 · 주변기기

- **영상 장비(모달리티)**: PACS 가 워크리스트 조회(C-FIND) 응답 · 검사 진행 상태(MPPS) · 영상 수신(C-STORE)을 맡습니다(`구현·미검증`). 장비 쪽 등록 값(AE 타이틀 등)의 설정 절차는 `확인 필요(따라가기)`.
- **외부 PACS · 기관 간 영상 교환**: 원격 DICOM 노드 조회 · 가져오기 · 보내기와 IHE XDS-I.b 제출이 있습니다(`구현·미검증`).
- **검사 장비(분석기) → LIS**: 결과 자동 수집은 `미구현` 입니다(⑥).
- **라벨 프린터(ZPL) · WebUSB 장치**: Go-Live 에서 자가신고로 추적합니다. 연결 절차는 `확인 필요(따라가기)`.

## ③ 설정

### LIS

- 설치 뒤 기관이 넣는 사이트 값(외부 통보 채널 · 오프사이트 백업 경로 등)은 LIS 의 **개시 전환 센터** 체크리스트로 입력 순서와 완료를 확인합니다.
- HIS 와의 검사 오더 경로는 **FHIR 폴링**(LIS 가 HIS 의 검사 오더를 5분 주기로 증분 조회)입니다. LIS 가 HIS 를 조회하는 데 쓰는 계정 · 권한의 준비 절차는 `확인 필요(따라가기)`.
- Reflex 추가검사 오더의 전송 방식 키 `HIS_ORDER_TRANSPORT` 가 있습니다. HL7(ORM) 쪽 경로는 `미구현` 이므로 FHIR 경로를 씁니다.
- HL7 MLLP 구간은 원내 폐쇄망인지 확인하거나, 상대 시스템과 전송 구간 보호(TLS · 전용 VPN)를 합의합니다(LIS 저장소 문서).
- 지표 엔드포인트의 접근 범위는 앞단 프록시에서 기관 망 정책에 맞춰 좁힙니다.

### PACS

- 🔴 **AI 기본값**(2026-09-11 코드 확인): 판독문 자동 초안 · 드리프트 자동 격리는 기본 꺼짐이고, **영상 자동 선별은 기본 켜짐**입니다. 설치할 때 끄고, 기관 결정 뒤에 켭니다 → [S6](S6-ai.md). 설정 키는 `screening_enabled`(환경 변수 `SCREENING_ENABLED`).
- 🔴 **설치본 주소**: 코드 기본값 가운데 특정 설치본의 주소가 들어 있는 설정(프레임 캐시 예열 기본 주소 등)이 있습니다. 자기 기관 주소나 내부 주소로 바꿉니다. 전체 목록은 `확인 필요(따라가기)`.
- **HL7 수신 허용 대역**: 앱의 허용 대역 설정과 호스트 방화벽 허용 대역을 **함께** 맞춥니다. 저장소의 통합 테스트 스크립트로 확인합니다.
- **선택 기능**: IHE ATNA 감사 송신 · 모달리티 구간 DICOM TLS 는 기본 꺼짐입니다.
- **백업**: 오프사이트 대상은 설정해야 켜집니다. 암호화 백업의 패스프레이즈는 서버 밖에도 보관합니다.
- **앞단 프록시**: PACS 앞에 역방향 프록시를 한 단 더 두는 구성이면, PACS 저장소의 해당 운영 기록(v13.48)을 먼저 읽고 구성합니다.

### HIS 쪽

- HIS 는 영상 오더를 만들 때 PACS 워크리스트에 자동 등록하고, 실패분을 다시 등록합니다.
- PACS 는 HIS DB 를 **읽기 전용**으로 조회해 워크리스트를 동기화합니다(관리자 요청 시). 읽기 전용 계정 준비 절차는 `확인 필요(따라가기)`.
- 영상 바이트 중계(WADO)는 배포 구성(주소 · 앞단 프록시)에 따라 달라져 코드만으로 판정하지 못했습니다(`판정 불가`).

## ⑦ 흔한 함정

- **HL7 허용 대역을 한쪽만 바꾸는 것.** 앱과 호스트 방화벽 중 한쪽만 바꾸면 연결이 **조용히** 끊깁니다.
- **운영 설치에 `demo` 시드를 쓰는 것.** 운영은 `starter` 입니다.
- **같은 호스트에서 compose 프로젝트 이름이 겹치는 것.** 다른 시스템의 컨테이너와 충돌합니다.
- **PACS 작업자 코드를 고치고 이미지를 다시 빌드하지 않는 것.** 작업자는 코드가 이미지에 들어갑니다.
- **Reflex 전송 방식을 HL7 로 바꾸는 것.** 그 경로는 아직 없습니다.
- **Go-Live 의 `integ.lis` 를 개발 시드 결재로 채우려는 것.** 개발 시드 결재는 세지 않습니다.
- **LIS 버전을 올리며 화면 표기 상수를 빠뜨리는 것.** 화면 표기용 버전 상수가 패키지 버전과 따로 있습니다.
- **백업 패스프레이즈를 서버에만 두는 것.**
