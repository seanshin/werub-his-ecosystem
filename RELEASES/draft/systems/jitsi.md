# Jitsi — 릴리즈 요약

> 기준 버전 **1.0.0** (정본 위치: `api/package.json version` · 태그 표기는 v2.10.0 — 7절) · 기준 커밋 `0984fbec7177` (2026-07-24)
> 요약 범위: v1.0.0 ~ v2.10.0 태그 중 최근 5개(v2.7.0 ~ v2.10.0 · 2026-06-18 ~ 2026-07-23) + 마지막 태그 이후 커밋(2026-07-23 ~ 2026-07-24) · 작성 2026-09-11
> 사실 확인: 미확인 — 생태계 자료 측 조사 기준(시스템 담당 확인 전)

## 1. 한 줄 정의와 계층

- **정의**: 원격진료 화상 서버입니다. 자체 호스팅하는 Jitsi Meet 구성(웹 · XMPP 시그널링 · 회의 관리 · 미디어 중계)에 TURN · 녹화 · 회의 관리 REST API · 모니터링을 더한 묶음입니다.
- **계층**: ⑦ 협업 · 교육 계층(원격 상담)
- **구현 상태**: `중단` — **현재 설치본은 동작하지 않으며 구축 기관은 새로 구성해야 합니다.** 아래 내용은 기준 커밋의 코드와 기록에 대한 설명입니다.
- **규모**: 기본 구성 컨테이너 9 — `data/scale-snapshot.json` 의 `systems.jitsi.counts.containers`(2026-09-11 계측 · 선택 구성 파일에만 있는 서비스 2개는 따로 셈 · 센 방법은 `rule`)

## 2. 이 버전에서 할 수 있는 것 (도메인별)

**화상 진료 입장**
- HIS 가 발급한 JWT 로 방에 들어갑니다(의사 = 진행자 · 환자 = 게스트). 시그널링 서버가 토큰을 검증한 뒤 입장을 허용합니다.
- 입장 전 화면에서 카메라 · 마이크 미리보기와 동의 절차를 거칩니다.
- 화면 문구는 한국어로 바꿔 두었습니다.

**회의 관리 API**
- 회의 예약 · 목록 · 설정 변경 · 종료, 참가자 목록 · 내보내기 · 음소거, 참가 토큰 발급 · 검증 · 참가 URL 생성, 녹화 시작 · 중지 · 상태 조회를 REST API 로 제공합니다. OpenAPI 문서가 함께 나옵니다.
- API 키로 인증하고, 키마다 권한을 세 단계(`admin` · `operator` · `readonly`)로 나눕니다.
- 참가자 입장 · 퇴장과 회의 상태 변화를 실시간으로 감지해 기록하고 웹훅(회의 시작 · 종료 · 참가자 입장 · 퇴장 · 녹화 시작 · 완료)으로 알립니다.

**녹화**
- 서버 쪽 녹화(Jibri) · 녹화 관리 화면(검색 · 메모 · 태그) · 보존 기간이 지나면 자동 만료 · 녹화 보안 등급과 감사 로그 · 녹화 중 표시(진행자에게만).
- 녹화 파일을 S3 호환 객체 저장소에 올리도록 설정할 수 있습니다(선택).

**AI 보조(선택 구성)**
- 녹화를 AI Server 로 보내 녹취록 · 요약 · 할 일 · 주요 장면의 **초안**을 받습니다.
- 실시간 자막(한국어 음성 인식) · 영어 번역 자막 · 채팅에 "원문 (번역)" 병기를 선택 구성으로 켤 수 있습니다. 음성 인식과 번역 연산은 AI Server 가 맡습니다.

**모니터링**
- Prometheus 지표 · Grafana 대시보드(서비스 상태 · 사용량 · 녹화 저장 용량 · API 트래픽) · 알림 규칙과 서명된 링크로 여는 알림 상세 페이지.
- 외부 오류 모니터링 SDK 를 붙일 자리가 있고, 화면 캡처에서 영상 · 환자 정보 · 채팅 · 표시 이름 · 자막을 가립니다.

**보안**
- TURN 중계를 통한 내부망 접근 차단 · 내부 콜백 비밀값(설정했을 때) · 웹훅 등록 · 발송 대상을 공개 https 호스트로 제한 · JWT 알고리즘 고정 · 요청 속도 · 본문 크기 제한 · 컨테이너 자원 상한.

## 4. 연동 변경 (릴리즈 기록상)

실제로 동작하는지는 통합 릴리즈의 `compatibility.md` 에서 판정합니다.

| 상대 | 변경 | 버전 |
|---|---|---|
| HIS (원격진료 입장) | HIS 와 공유하는 비밀키로 서명한 JWT(HS256)를 받습니다. 토큰 검증 알고리즘을 HS256 으로 고정했습니다 | v2.9.0 |
| HIS (참가 토큰) | 자막 버튼은 참가 토큰의 전사 기능 표시(`features.transcription`)에 따라 켜집니다 | 태그 이후 |
| AI Server | 실시간 전사 · 번역 자막을 AI Server 의 음성 인식 · 번역에 연결했고(선택 구성), AI 응답의 예외 처리를 넓혔습니다 | v2.7.0 ~ v2.9.0 |
| 외부 플랫폼(REST API) | 웹훅 대상은 공개 https 호스트만 허용합니다 | v2.9.0 |

## 5. 알려진 한계

- **현재 설치본은 동작하지 않으며 구축 기관은 새로 구성해야 합니다.**
- **로그인 방식** — HIS · Jitsi · 회의 관리 API 세 곳이 같은 공유 비밀키(HS256)를 가져야 합니다. 여러 시스템이 쓰는 공개키 검증 방식이 아니므로, 비밀키를 따로 보관하고 교체하는 관리가 필요합니다.
- **모바일 웹** — 지원이 보류돼 있고 차단된 상태입니다.
- **실시간 자막 · 번역** — 시험 구현에서 시작한 선택 구성입니다. 무음 구간의 오인식을 완화했지만 남은 과제로 적혀 있고, 동시에 전사할 수 있는 세션 수에 상한이 있습니다.
- **내부 콜백 보호** — 내부 콜백 비밀값(`INTERNAL_SECRET`)을 설치할 때 반드시 설정합니다(6절).
- **문서 불일치** — README 의 릴리즈 표는 v2.3.0 에서 멈춰 있습니다(7절).
- 연결별 동작 상태는 `compatibility.md` 에서 판정합니다.

## 6. 설치 · 업그레이드 시 주의

- **새로 구성하는 것을 전제로 합니다.** 기본 구성 파일로 9개 컨테이너를 올리고, 실시간 자막은 별도 구성 파일을 겹쳐 켭니다(선택).
- **필수 설정** — 도메인 · 공인 주소 · JWT 공유 비밀키(HIS 쪽 값과 같아야 함) · TURN 비밀값. 구성요소 비밀번호를 만드는 스크립트가 있습니다.
- **방화벽** — 미디어 중계와 TURN 용 UDP · TCP 포트를 방화벽의 모든 계층에서 열어야 합니다. 한쪽만 열면 3명 이상 통화에서 영상이 끊긴다고 문서가 적습니다. 포트 목록은 소스 저장소 README 에 있습니다.
- **녹화** — 녹화 컨테이너는 호스트의 사운드 장치와 추가 권한이 필요합니다.
- **운영 전에 정할 것** — 내부 콜백 비밀값(`INTERNAL_SECRET`) 설정 · API 키 발급과 권한 · 녹화 보존 기간 · 녹화 외부 저장 여부.
- **리버스 프록시** — 저장소의 경로별 프록시 설정 파일을 기준으로 삼습니다(예전 설정 파일은 폐기 표시돼 있음). 관리용 대시보드는 기본으로 서버 안에서만 열립니다.
- **웹 설정 반영** — 인터페이스 설정 파일을 바꾸면 웹 컨테이너를 다시 만들어야 반영됩니다. 자막 구성을 쓰는 경우 두 구성 파일을 함께 지정해 다시 만듭니다.

## 7. 버전 표기와 근거

- **버전 표기의 어긋남**(매니페스트 등급 `주요`)
  - 코드 선언(`api/package.json` · API 서버 코드)은 1.0.0 이고, 같은 이름의 태그 v1.0.0 은 2026-05-29 에 달렸습니다(매니페스트 릴리즈일). 이후 태그는 v2.10.0 까지 이어졌지만 코드 선언은 올리지 않았습니다. 기준 커밋은 v2.10.0 태그 이후 커밋 9개를 더 포함합니다.
  - 정본 규칙상 코드 값(1.0.0)을 기준 버전으로 두었습니다. 공개 자료에 어느 표기를 쓸지는 시스템 담당 확인 뒤 정합니다. 그 전까지 **1.0.0(코드 선언) · v2.10.0(태그)** 을 함께 적습니다.
- **근거 기록**
  - 저장소 태그 23개(v1.0.0 ~ v2.10.0 · 마지막 2026-07-23). 이 요약은 최근 5개와 태그 이후 커밋을 썼습니다.
  - README 의 릴리즈 표 — v2.3.0 에서 멈춰 있습니다. 태그가 없는 판(v2.0.2 · v2.1.0 · v2.2.0)도 이 표에만 있습니다.
  - 저장소 작업 지침 문서(`CLAUDE.md`)의 릴리즈 표 — v2.10.0 까지 있어 태그 설명의 보충 근거로 썼습니다.
  - 이 요약과 수치는 기준 커밋의 내용만 봅니다(작업 트리의 커밋하지 않은 변경은 들어가지 않습니다 — `data/base-commits.json`).
