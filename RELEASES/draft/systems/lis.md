## 2. 이 버전에서 할 수 있는 것 (도메인별)

**진단검사**
- 처방 수신(HIS 에서 FHIR 로 받음) → 접수 · 라벨 → 검체(분주 · 거부 · 재채취) → 결과(장비 자동 입력과 수기 입력) → 자동 검증 · 델타 체크 → 2차 검증 → 위험치 폐루프(통보 · 상향 · 복창 기록) → 보고 · HIS 회신 → 청구 캡처까지 이어집니다.
- 참고치가 없거나 단위가 맞지 않으면 자동 확정을 막고, 입력자와 검증자가 같으면 검증을 막습니다.

**미생물**
- 배양 등록 → 그람 예비보고 → 동정 → 감수성(전문가 규칙) → 다제내성균 판정 · 격리 → 법정감염병 신고(신고 서류와 신고 번호가 있어야 완료) → 누적 항균제 감수성 통계.

**병리**
- 접수 → 그로싱 → 블록 → 슬라이드(H&E · 특수 염색 · 면역조직화학) → 동결절편 복창 → 판독 → 구조화 보고 → 2단계 사인아웃 → 개정 · 추가 보고 → PACS 의 슬라이드 영상 조회.

**수혈**
- 혈액형 · 항체 → 입고 · 유효기간 → 교차시험 자동 판정 → ABO 부적합을 막는 독립 판정 → 출고 → 시행(2인 확인) → 부작용 조사.

**유전체 · 분자진단 · NGS**
- 동의 → 수탁 · 시퀀싱 → 변이 입력(VCF · 수기) → ACMG 기준 큐레이션 → 해석 확정 → 이차 소견 동의 게이트(동의가 없으면 건수조차 보여주지 않음) → 보고서 서명 · 배포 → 재분류.
- **해석 초안 보조** — 내장 지식기반과 ACMG 규칙으로 변이 해석 초안을 만듭니다. 외부 LLM · 클라우드로 데이터를 보내지 않으며, 초안은 판독 전문가가 검토 · 수정해 확정합니다.
- 분자진단 검사 카탈로그(판정 기준 · 보류 구간)와 NGS 런 품질 기준을 관리합니다.

**품질 관리**
- 내부 정도관리(Westgard 규칙 · Levey-Jennings) · 외부 정도관리 · 장비 목록 · 소요 시간(TAT)과 재검률 통계.

**거버넌스 · 개시 전환**
- 반사 검사(Reflex) 승인 프로토콜(4-eyes) · 조직 결재 게이트 · 검사실 서명 기록 · 조직 결정 등록.
- **개시 전환 센터** — 개시 체크리스트 · 개시 키 · 전환 실행을 한 화면에서 합니다. 시스템이 판정할 수 있는 항목은 사람이 완료로 찍지 못하게 하고, 근거가 필요한 항목은 첨부 문서 없이 완료할 수 없습니다. 첨부 문서는 내려받을 때 해시를 다시 계산해 바뀌었는지 알립니다.
- 파일럿 데이터 정리는 시드가 만든 행만 지우고, 실제 환자 데이터가 감지되면 거부합니다. 요청과 승인을 다른 관리자가 각자 인증해 두 단계로 실행하며, 막힌 시도까지 기록합니다.

**운영 · 보안**
- 연계 감시 지표 · 실패 메시지 대기열(DLQ)과 재적재 · 다운타임 오더 · 외부 위탁 · ERP 청구 송신.
- 변경과 민감 조회를 자동으로 감사 기록에 남깁니다. 감사 기록은 해시체인이며, DB 트리거가 수정을 막습니다. 보존 기간은 법정 하한을 설정 저장 시점과 적용 시점 모두에서 강제합니다.
- 권한은 기능 × 역할 매트릭스로 관리합니다. 서명 · 승인 주체는 요청 본문이 아니라 서버가 로그인 정보로 정합니다.

**표준 · 코드**
- FHIR(HIS) · HL7 v2 MLLP 워크리스트 송신과 QIDO-RS 조회(PACS) · ASTM E1394 / CLSI LIS2-A2 · CSV(검사 장비).
- LOINC · SNOMED CT · ISBT 128 · HGVS/VCF · 청구 수가 코드를 씁니다. 코드와 미생물 판정 기준표는 기관이 반입하는 구조이며, 이용 조건은 [THIRD_PARTY.md](../../../THIRD_PARTY.md#4-코드-마스터기준-데이터)를 봅니다.

## 4. 연동 변경 (릴리즈 기록상)

- 이 범위(1.56.11 ~ 1.56.18)에는 연동 규격 변경이 없습니다.
- 저장소 문서가 적은 현재 연동 방식:
  - **HIS** — FHIR 전용입니다. 검사 처방(ServiceRequest)을 증분 폴링으로 받고, 결과(DiagnosticReport)를 원 처방에 결속해 보냅니다. HIS 구간의 HL7 v2 는 채택하지 않았고, HL7 수신 코드는 다운타임 대체 경로로 남아 있습니다.
  - **PACS** — 병리 워크리스트를 HL7 v2(ORM^O01) MLLP 로 보내고, 영상은 QIDO-RS 로 조회해 뷰어를 엽니다.
  - **검사 장비** — ASTM · CSV 파서.
  - **ERP** — 청구 송신(HMAC 서명).
- 파일럿 데이터 정리는 LIS 데이터만 지웁니다. 파일럿 기간에 다른 시스템으로 보낸 데이터는 개시 체크리스트의 별도 항목으로 상대 시스템과 함께 정리합니다(1.56.9 ~ 1.56.13 문서 · 체크리스트).
- 이 연결들이 실제로 동작하는지(5단계 연동 상태)는 통합 릴리즈의 `compatibility.md` 에서 판정합니다.

## 5. 알려진 한계

저장소 문서가 스스로 밝힌 것입니다.

- **MLLP 송신은 TLS 없이 TCP 로 동작합니다.** 해당 구간이 원내 폐쇄망인지 확인하거나, MLLP over TLS · 전용 VPN 을 상대 시스템과 합의해야 합니다(저장소 수용 위험 문서).
- 직원 계정은 LIS 자체 계정입니다(HIS 직원 신원과 연결되지 않음). 입사 · 퇴직 때 LIS 계정을 따로 만들고 회수합니다.
- 한 설치본은 한 기관입니다(사이트 = 서버 = DB). 여러 기관을 한 설치본에 넣는 구조는 채택하지 않았습니다.
- 웹 화면에는 자동 테스트 하네스가 없습니다. 화면 쪽 회귀는 lint(경고 0 게이트)와 API E2E 로 잡습니다.
- 보존 기간이 지난 데이터의 파기(수명주기 정리)는 기관이 보존 기간을 정한 뒤 켭니다.

## 6. 설치 · 업그레이드 시 주의

- **설치 단위** — 준비된 호스트에서 설치 스크립트 한 번으로 올라오도록 돼 있습니다. 스크립트는 비밀값을 무작위로 만들고, 마이그레이션 적용을 확인하고, 백업 크론을 등록하고, 관리자 초기 비밀번호를 한 번만 출력합니다. 기존 환경 파일은 덮어쓰지 않고 멈추며, http 주소는 거부합니다. 검증 스크립트는 "떴다"가 아니라 "쓸 수 있다"를 봅니다(무인증 차단 · API 문서 비노출 · 백업 크론 등록).
- **시드 프로파일** — `starter` · `demo` · `all` 을 고릅니다. 운영 설치는 `starter` 로 하고, 데모 환자 · 데모 직무 계정은 `demo` 에만 있습니다.
- **배포** — 배포 스크립트가 E2E 게이트 통과를 먼저 요구하고, 빌드 캐시 없이 빌드합니다. 같은 호스트에 다른 시스템의 컨테이너가 있으면 compose 프로젝트 이름을 고정해 충돌을 막습니다(저장소 문서).
- **지표 엔드포인트** — 1.56.17 부터 루프백과 사설 대역에서 읽을 수 있습니다. 같은 사설망의 다른 서비스도 읽을 수 있다는 뜻이므로, 더 좁혀야 하면 앞단 프록시에서 함께 제한합니다.
- **1.56.0 이전에서 올릴 때** — 파일럿 데이터 정리 API 가 한 번 호출에서 요청 → 승인 두 단계로 바뀌었습니다.
- **개시 전** — 외부 통보 채널 · 오프사이트 백업 경로 같은 사이트 값은 설치 뒤 기관이 넣고, 개시 전환 센터 체크리스트로 입력 순서와 완료를 확인합니다.
- 화면 표기용 버전 상수가 패키지 버전과 따로 있어, 버전을 올릴 때 함께 바꿔야 화면 표기가 맞습니다(7절).
